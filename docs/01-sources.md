집성은 원 사서의 발췌이며 ZIP의 92종과 포털 설명의 95종 차이를 남겼다. 알 수 없는 편찬 시점은 미상으로 표시한다.
[승정원일기](research/seungjeongwon-ilgi-ingestion.md), [비변사등록](research/bibyeonsa-deungnok-ingestion.md),
[고순종실록](research/gosunjong-sillok-ingestion.md)도 두 번 추출하고 XML을 별도로 세어 대조했다.
승정원일기는 상위 일자의 날짜를 기사에 연결하고 원래 날짜 형식·편집 표지를 따로 보존한다.
비변사등록은 기사 외에 권별 서지 273개를 구분했다. 고순종실록은 1935년 편찬 자료로 기존 실록 30종과 다른 묶음이다.
실제 XML에 비변사등록 1616년 기사 3개와 순종실록부록 1928년 기사가 있어 카드 범위에 반영했다.
그 사이 기록이 없는 해를 새로 채우지는 않았다.
벌크 XML 의 구조·계층 차이는 `docs/research/bulk-xml-findings.md`.

## 사료는 두 종류다

| 종류 | 예 | 저작권 | 어떻게 넣나 |
|---|---|---|---|
| **옛 기록** | 삼국사기, 실록, 비석 | 원문은 소멸 (자유) | 한문 원문은 그대로 넣어도 된다 |
| **현대 연구** | 국편 『한국사』, 교과서, 논문 | 살아있음 | 주장만 요약해서 넣고 출처를 단다 |

번역문은 원문과 다르다. 한문 원문은 자유롭지만 **한글 번역문은 번역자의 저작물**이라 따로 본다.

**기본 렌즈는 현대 연구 쪽**이다. 다만 그것도 "국편 한국사가 이렇게 본다"라는 각주 달린 주장으로 들어간다.

## 각 사료에 붙일 정보

수집할 때 사료마다 이 항목들을 채운다. 스키마의 Source 노드가 될 것들이다.

- **이름** / 원제
- **언제** 만들어졌나
- **누가** 만들었나
- **어느 시대**를 다루나 (기록 대상 시기 ≠ 편찬 시기)
- **성격** — 관찬사서 / 개인 저술 / 금석문 / 외국 기록 / 현대 연구
- **조심할 것** — 편찬자의 입장, 알려진 왜곡·논쟁
- **입수처** — URL
- **라이선스** — 자유 / 조건부 / 확인 필요
- **원문 언어** — 한문 / 한글 / 일본어 / 중국어

**우리는 진위를 판정하지 않는다** — 판정하는 학계의 주장도 하나의 Claim으로 넣는다.

## 아직 안 정한 것

1. **어디부터 넣을 것인가.** 통사 뼈대를 깐다고 했지만 전부 동시에는 못 한다. 한 시대를 먼저 제대로 채워
   파이프라인을 굴려보는 게 순서일 것 같다 — 삼국이 후보다(충돌이 많아 시스템 성격이 드러남).
2. **자동 수집이냐 손으로냐.** 실록처럼 정형화된 건 긁어올 수 있고, 금석문처럼 판독 자체가 논쟁인 건
   사람이 넣어야 한다. 사료마다 다르다.
3. **번역문을 쓸 것인가.** 한문 원문만 넣으면 저작권은 깨끗한데 읽을 수가 없다. 공공기관 번역이
   자유롭게 쓸 수 있는지에 달렸다.
4. **북한 사료·연구를 어떻게 다룰 것인가.** 현대사 구간에서 반드시 마주친다.
