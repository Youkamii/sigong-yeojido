# 이름 없는 마을·논밭·호랑이 — #117

사용자가 역사 기록이 없는 빈 땅에도 마을·밭·호랑이를 놓도록 요청했다. 현재 기록의 인물·사건을 배치한 뒤,
완만한 한반도 본토에 작은 마을 18개(집 92채)와 논밭 72개, 숲의 빈틈에 호랑이 18마리를 만든다.
마을에는 작은 길, 수레와 주민도 있다. 장소가 바뀌어도 배경 위치는 일정하다.

이름 없는 배경은 역사 지명·Claim·근거 선택 대상에 들어가지 않는다. 사료를 모두 끄면 역사 장면·지역 이름은
사라지고 이 배경만 남는다. 실제 사건과 겹치는 배경은 숨기며, 숨긴 마을 때문에 숲이 비지 않도록 함께 갱신한다.
호랑이는 나무 수관에 가리지 않는 작은 숲속 빈터에 놓는다. 논밭은 공통 경사면을 써서 흙과 작물이 교차하지 않는다.

생성은 마을마다 브라우저에 실행을 양보하며, 마을 안의 모델은 기존 생성기로 묶는다. 가까운 배경만 동작을 갱신한다.
역사 장면 준비와 비동기 배경 준비 시간을 따로 기록하고, 배경까지 만들어진 뒤 실제 프레임 간격으로 성능을 잰다.

실제 c2 API를 연결한 로컬 화면에서 [9개 검사](decorative-scenery-local-117.json)가 통과했다.
[마을·밭](decorative-village-117.png)과 [호랑이](decorative-tiger-117.png) 화면을 직접 확인했다.
북쪽·남쪽 분포, 육지 배치, 나무 간격, 사료 해제, 드래그와 브라우저 오류를 검사했다.
JS 에셋·좌표·해안선 검사도 통과했다.

이는 특정 연도의 실제 마을·농법·동물 분포를 복원한 자료가 아니다. 시대별 생활상이나 한국사 전체의 자료 수록을
완료했다는 뜻으로 쓰지 않는다. 새 역사 조사나 Claude 호출은 이 변경에 없다.
