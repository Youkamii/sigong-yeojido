# 시대와 활동에 맞춘 사건 구성

원본 26개 조형을 보존하고 제철소·역·열차·차량·기관 선박·공공건물·발사체·근대 병사 등 설명용 조형 8개를 추가했다. 역사 건축물이나 군복을 실측 복원한 모델이 아니다. 각 부분은 기존 Fantology 조형 생성기와 재질 규칙을 사용한다.

철도·도로 개통, 산업 시설, 발사, 사찰 건설, 야외 전투를 다른 구성으로 표시한다. 육상 출항은 항구 구성으로 처리하며 배를 육지에 놓아 장면이 사라지는 문제를 수정했다. 함선 근거가 있는 해안 공성전은 가까운 물 위에 함대를 배치한다. 출처에서 상륙 지점이 없다고 설명한 문장을 상륙 연출 신호로 쓰지 않는다.

개인 분신 사건에 주변 건물 화재를 만들지 않는다. 전태일 장면의 법전 화형식은 근거가 연결된 작은 책과 불로 표현한다. 최제우의 용담정 수련에는 수집 내용이 배제한 시위 군중을 넣지 않는다. 노량에서는 명 수군과 조선 수군의 소속 표시와 지휘선 배치를 구분한다. 서로 다른 편의 현장 인물이 같은 좌표에 겹치지 않도록 자리를 나눴다.

조형 34개와 근대 병사의 동작 정규화 검사 PASS. 실제 공개 화면 검사는 배포 뒤 별도 기록한다.
