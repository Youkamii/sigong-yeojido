# 실제 역로 자료의 추가 조사 (#57, #86)

2026-09-07 Claude Opus 5 / max 호출이 후보 6개를 확인하고 정상 종료했다.
재배포 가능한 한반도 역사 역로 선·역로를 담은 좌표 연결 고지도는 **확보 0개**다.
[조사 원본](../../data/research/historical-routes-57/result.json)과
[실제 호출](../../data/research/historical-routes-57/run.json)을 보존했다.

| 확인 후보 | 확인 결과와 한계 |
|---|---|
| JCAA 조선 도로 연구 | 논문은 CC BY 4.0이나 사용한 도로 벡터의 공개 파일을 찾지 못했다. 논문 이용조건을 인용 데이터에 대신 적용하지 않았다 |
| 2025년 조공로 재구성 논문 | 중국 요동의 역참 구간을 다룬다. 환경·기초 지도 입력만 안내되고 결과 선 파일은 미확보이며 한반도 구간으로 세지 않았다 |
| 국가유산 공간정보 | 포털의 SHP·이용조건은 확인했으나 지정 구역과 길 중심선을 구별해야 한다. 실제 파일의 도형 종류와 역사 기간은 이번 조사에서 미검증이다 |
| Zenodo·OSF·figshare | 사용한 검색에서 적합한 파일을 찾지 못했다. 전체 저장소에 자료가 없다는 증명은 아니다 |
| David Rumsey | 이용조건은 확인했으나 지도 목록에 봇 확인 화면, 좌표 연결 사이트에 403이 나타나 특정 한국 지도를 검증하지 못했다 |
| Wikimaps Warper·MapWarper | 전자는 한국 검색의 해도 5건으로 역로를 확인하지 못했고, 후자는 CAPTCHA로 중단했다 |

원 조사 호출은 작업 폴더 제한 때문에 기존 저장소 보고서를 읽지 못했다. Codex가 기존 수집·접근 기록과 대조했다. 기존 HGIS·Cliopatria 경계와 사건 장소를 역로 수집으로 바꾸지 않는다.

[선 표시 기능](route-rendering-86.md)의 인공 자료·기존 경계 회귀 검사는 통과했지만 실제 역사 선 수용은 **NOT_RUN**이다. 출처가 그리지 않은 선을 역참 점 사이에 만들거나 현대 도로를 그대로 역사 역로로 올리지 않았다.
