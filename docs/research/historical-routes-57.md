원 조사 호출은 작업 폴더 제한 때문에 기존 저장소 보고서를 읽지 못했다. Codex가 기존 수집·접근 기록과 대조했다. 기존 HGIS·Cliopatria 경계와 사건 장소를 역로 수집으로 바꾸지 않는다.

[선 표시 기능](route-rendering-86.md)의 인공 자료·기존 경계 회귀 검사는 통과했지만 실제 역사 선 수용은 **NOT_RUN**이다. 출처가 그리지 않은 선을 역참 점 사이에 만들거나 현대 도로를 그대로 역사 역로로 올리지 않았다.

## 현재 옛길 파일의 추가 확인

공공데이터포털 [국가숲길 코스 15108080](https://www.data.go.kr/data/15108080/fileData.do)의 공식 다운로드 버튼 흐름으로 익명 ZIP을 받았다. 원 파일은 1,142,834바이트이며 SHA256은 `53cd9e503b5f4d564516bfd8d39c0c9b0d9dc62d56ecb5d4ca015efc554a9950`이다. GPX **56개와 코스 범례 XLSX 1개**가 들어 있다. 전부 역사 역로인 것은 아니다.

이전 조사자의 WebFetch는 자바스크립트 다운로드를 실행하지 못했다. 로그인 필요나 접근 금지로 확정할 근거는 없었고, 실제 공식 공개 다운로드로 정정했다. 최초 조사와 두 차례 후속 대조의 [실행·판정 원본](../../data/research/preserved-routes-57/)을 함께 보존한다.

범례의 `대관령숲길 / 대관령옛길 / 0000000008`은 실제 GPX 파일과 일치한다. 단일 구간의 **932개 좌표**이며 파일 해시·원 순서·좌표 해시를 [별도 파서](preserved-route-file-57.json)로 대조했다. GPX 1.1 선언은 WGS84 해석의 근거이고, 파일 전체의 XSD 검증을 한 것은 아니다. 모든 고도 값이 0이고 지점 시각이 같아 고도·소요시간·속도의 실측 근거로 쓰지 않는다.

[국가유산청 설명](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?ccbaCpno=1353200740000)의 본문도 실제 페이지가 불러오는 같은 호스트의 공개 HTML에서 확인했다. 짧은 역사 설명은 별도 Source로 수록할 수 있지만, 이 932점이 지정구역이나 고려·조선의 노선과 같은 도형이라는 근거는 없다. 현재 트랙과 역사 설명은 서로 다른 엔티티로 둔다. 본문 전체는 재배포하지 않고 URL·응답 해시·짧은 인용만 남긴다.

최종 Claude Opus 5 / max 대조는 **현재 참고 자료 수록 가능, 과거 연도에 유효한 역사 역로 수록 불가**로 판정했다. #88에서 2023-08-25 기준 안내 코스와 별도 설명을 표시한다. #57/#86의 과거 역사 선 미확보 상태는 유지한다. 상세 페이지의 렌더링 실패를 공식 설명의 부재로 판단하지 않았고, 차단된 사이트나 TLS 검증 실패는 우회하지 않았다.

```sh
python scripts/inspect_preserved_route.py --out /tmp/preserved-route-file.json
```

이 명령은 Git에 보존한 원 ZIP과 범례·GPX를 다시 읽는다. 현재 트랙을 옛길로 새로 추정하거나 경유지 사이에 선을 생성하지 않는다.
