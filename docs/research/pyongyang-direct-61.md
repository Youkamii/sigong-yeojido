# 비문 평양과 후대 천도지의 직접 동일성 견해 (#61)

苗威의 「高句丽“平壤城”考」(2011, 《中国历史地理论丛》26권 2기)를 전재한 페이지를 확인했다.
저자는 비문 399년의 下平穰, 404년의 平穰 등을 열거한 문장에서 대동강 북안 평양으로 비정한다.
같은 절에서 427년 천도지를 하평양으로 설명한다.

이를 해당 저자의 `sameEntityAs` 세 건으로 기록했다. 서로 다른 표기의 엔티티 네 개는 유지한다.
전역 병합이나 검색 별칭 변경, 좌표 생성은 하지 않았다. 단일 연구자의 해석이며 학계의 확정 판정이 아니다.
穰/壤의 자형 관계를 직접 설명한 것으로도 처리하지 않는다.

Claude Opus 5 / Max 조사 후 Codex가 원 HTML을 별도로 받았다.
원문은 곡선 인용부호와 줄바꿈을 사용하므로 조사 추출본의 인용을 그대로 복사하지 않았다.
문장 끝의 的/之 차이도 확인했다. 공개 인용은 원문 그대로 총 24자이며 문맥 위치와 원 링크를 붙였다.

[파일 해시·인용·세 연결](pyongyang-direct-61.json). 재적재해 내용이 같음을 확인했다.
기존 근거·참조·digest 검사로 확인하며 실제 운영 그래프 검사는 다음 배포 기록에 남긴다.
원 학술지 지면과 전재본의 판본 대조는 아직 없다. 기관 연락 없이 새 터미널 창을 열지 않고 실행했다.
