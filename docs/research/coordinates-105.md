# 공통 좌표와 지역 배치

Claude Opus 5 / Max가 지역·유적 좌표 82개를 수집했다. 실제 종료 코드 0, 응답 모델, 다운로드 매니페스트와 원본 해시를 확인했다. 현대 행정구역과 역사 지점을 구분했으며, 기존 HGIS 표시 기준점 354개와 함께 쓴다. 82개는 기록 수이고 고장 82곳을 뜻하지 않는다. 수집 범위와 남은 자료 한계는 [조사 보고](../../data/research/coordinates-105/report.md)에 있다.

3D 지형·장소·인물·사건·북위 38도선은 같은 좌표 변환을 쓴다. 지역 메뉴에서 평양·서울·부산·강릉 등을 고르면 해당 좌표로 이동하고 출처를 볼 수 있다. 38도선은 켜고 끌 수 있으며 현재의 군사분계선과 구별한다. 모바일 설명은 지도 안에서 스크롤된다.

정확한 현장 지점이 없는 경우, 자료에서 확인되는 활동 지역과 등록부를 연결해 **지역 기준 추정 배치**로 표시한다. 인물의 지역 활동은 해당 활동 자체에 기간이 있는 경우에 연결하며 생애 전체로 늘리지 않는다. 같은 이름으로 여러 위치가 남은 경우에는 하나를 임의로 고르지 않는다. 지역 대표점이 역사 인물의 실제 좌표라는 뜻은 아니다.

검사: 기존 좌표와 새 좌표 436개의 왕복 변환, 38도선, 다른 지명의 부분 일치 방지, 같은 이름의 구별, 기간이 있는 지역 활동을 Node에서 확인했다. 기존 역사·에셋·사료 분할 가져오기 검사도 통과했다. 실제 서버 API를 그대로 사용하는 로컬 화면에서 좌표·이동·출처·모바일 검사 **13개 PASS**, 브라우저 오류 0이었다. 공개판 검사는 배포 후 별도 기록한다. CI는 NOT_RUN이다.

조사·다운로드는 Claude, 구현·자료 대조·검사는 Codex가 수행했다. 위키데이터 좌표는 지리 기준점으로만 쓰며 역사 사건의 새 근거로 바꾸지 않았다.
