# 작은 생활 풍경과 산줄기·숲·길 — #119·#123

한반도 세계 배율 8을 유지하고 배경 가옥·논밭·호랑이의 크기를 줄였다. 마을마다 네 가지 배치 방식,
서로 다른 집 수와 방향, 세 가지 새 가옥 조형을 사용한다. 논밭은 개별 모양·크기·고랑·색을 달리한다.
현재 배경은 마을 56곳, 가옥 269채, 논밭 196개, 호랑이 16마리다. 실제 역사 장면과 겹치는 배경은 숨긴다.

산줄기는 좁은 능선과 넓은 산기슭을 나누어 표현하고, 9,583그루의 나무를 군락으로 배치했다.
나무를 99개 지역 묶음으로 그린다. 1593년에는 배경 마을 사이 길 57개가 보인다. 길과 나무가 겹치지 않게 한다.
땅 위 물체의 높이는 실제 지형 삼각형에서 구한다. 1,521개 육지 표본의 최대 오차는 약 6e-14다.
멀리서는 마을 모양을 유지하면서 도형을 합쳐 그린다. 나중에 생성되는 가옥·동물에도 그림자를 적용했다.

RTX 3060·1920×1080·medium·공개 주소에서 실제 프레임 간격을 쟀다. 모든 풍경 생성 뒤 정지 157.1fps,
이동 160.9fps, 전체 보기 145.3fps다. [전체 측정](landscape-performance-public-123.json)에 p95·최대 지연도 남겼다.
자료 준비 12.453초, 배경 준비 13.422초. 측정 중 다른 검사 브라우저는 실행하지 않았다.
초기 56개 마을 구현은 전체 보기 약 72fps였고, 먼 마을의 도형 묶음 처리 후 다시 측정한 값이다.

이 길은 장면을 잇는 배경 길이며 실제 대동여지도 역로를 복원한 선이 아니다. #86의 출처 있는 역로는 별도 미완료 범위다.
익명 배경은 사료에 없는 장소·인물·사건으로 저장하지 않는다. 시대별 주거·농경 변화와 실제 도시 구획 복원은 남는다.
저사양 실제 기기는 NOT_RUN이다. GitHub workflow 0개로 CI NOT_RUN이며 위 검사는 직접 실행했다.
