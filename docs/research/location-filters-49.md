# 지도와 RDF 후보 선택 대조 (#49)

출처가 없는 초기 좌표 후보는 뷰어에서 지명 언급 여부로 표시 여부를 정하고 있었다.
`/api/locations`와 그래프에는 그 조건이 빠져 있었다. 같은 실행 중인 원문 색인의 지명 목록을
RDF 조회 조건에 넘겨, 페이지를 자르기 전에 같은 후보를 고르게 했다.
지명 언급을 좌표 근거 Claim이나 `fromSource`로 바꾸지는 않았다.

실제 저장소 자료로 만든 Fuseki 22,647 triples와 뷰어의 공용 2D/3D 규칙을 대조했다.
전체 219개, 삼국사기 500년 40개, 삼국유사 100년 78개, 고려사 918년 62개의 ID와 좌표가 일치했다.
좌표 출처가 필요한 비교 후보, 전체 해제, AI 제외와 필터 뒤 페이지 이동도 통과했다.
이 수치는 로컬 원문 범위 기준이며 c2 전체 원문의 지명 언급 수는 다를 수 있다.

재현: `scripts/verify_location_filters.py --base http://127.0.0.1:8870 --out REPORT.json`.
[로컬 실행 기록](location-filters-49-local.json). 운영에서 같은 검사를 다시 실행한다.
