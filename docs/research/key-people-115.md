# 핵심 인물 기본 표시 #115

인물을 선택한 뒤에만 이름이 보이던 규칙을 제거했다. 현재 화면의 활동 인물 이름과
역할을 기본 표시하고 선택한 장면을 우선한다. 좁은 화면에서는 최대 3명, 넓은 화면에서는
최대 6명을 우선 배치하며 겹친 이름을 피한다. 사건과 일반 지리보다 현장 인물을 먼저 배치한다.
같은 인물이 여러 장면에 있어도 한 화면에 이름을 반복하지 않는다.

[한산도 장면](key-people-115.png)에서 이순신·이억기·원균·와키자카의 이름과 역할이
개별 인물 선택 없이 표시되는 것을 직접 확인했다. 지도 위치나 활동 사실을 추가하지 않았다.
[세계 탐색 29개 검사](key-people-115.json) 통과. 브라우저 오류 없음.
