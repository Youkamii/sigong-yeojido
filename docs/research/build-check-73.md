# 전체 TTL 검사 갱신 (#73)

1,086개 Claim의 실제 빌드는 정상인데 예전 `tests/check_build.py`의 검사 4개가 실패했다.
[최초 실패](build-check-before-73.json)를 보존하고 아래 판정을 고쳤다.

| 이전 판정 | 현재 검사 |
|---|---|
| `chunks.jsonl`만 읽어 새 클론의 실록 인용을 누락으로 판정 | 공용 로더가 전체 원문과 `citation-chunks.jsonl`을 대조하고 중복 없이 읽음 |
| TTL 어디에든 본문 앞 20글자가 있으면 누출 | Chunk 노드의 허용 메타데이터와 원 레코드의 값이 일치하는지 검사. Claim 인용과 설명은 허용 |
| 설명 속 `owl:sameAs`도 OWL 사용으로 판정 | 파싱한 IRI와 자료형을 검사하고 문자열 내용과 구별 |
| 여러 참여자·직함·계보를 충돌로 판정 | 공용 다치 술어 목록을 적용하되 판독 충돌은 계속 검출 |

본문 필드 추가·본문을 메타데이터로 위장·실제 OWL IRI/자료형·서로 다른 인용 복사본·
판독 충돌을 검사하는 회귀 4개를 추가했다. Python 93개·JavaScript 13개 통과.
[현재 전체 빌드 검사](continued-build-check.json)는 실패 0, 두 번 빌드한 바이트 일치,
927개 Chunk의 메타데이터·4,845개 참조·1,086개 digest·실제 판독 충돌 6개를 확인했다.
rdflib의 44,188 트리플 재파싱도 일치한다. `riot`은 설치되지 않아 NOT_RUN이다.

실제 애플리케이션의 판정을 느슨하게 만든 변경은 없으며 오래된 검사 프로그램을 현재 스키마에 맞췄다.
