# 전체 사료 선택에서 비교·시간 조회 지연 (#70)

운영에서 `verify_time.py`가 시간 근거를 연 뒤 백제 건국 비교로 이동할 때 두 번 실패했다.
30초 뒤에도 원표기·환산 버튼 대신 로딩 문구가 남았다. 비교에 필요한 환산 사료는 이미 선택된 상태였다.
격리한 로컬 API에서도 사료 996개를 지정한 비교 요청에 6.09초가 걸렸다.

시간 질의가 사료와 시간 범위·주장 ID를 각각 `VALUES`로 결합하고,
근거 그래프도 사료·객체 종류를 `VALUES`로 결합했다. 사료 조건을 `FILTER IN`으로 옮겨
이미 있는 그래프 행에서 선택한 사료만 남긴다. 사용자가 고른 사료를 임의로 빼지 않는다.

같은 실제 API 1회 대조는 6.09초에서 0.75초로 줄었고 원표기 3개·환산 2개는 같았다.
이는 해당 실행 관측값이며 보장 성능이 아니다. [측정](source-selection-performance-70.json)
시간 단위 검사 3개와 서버 검사 16개가 통과했다. 실제 화면에서는 원표기·환산 출처·
기원전 이동·사료 해제·AI 제외를 함께 확인한다.
