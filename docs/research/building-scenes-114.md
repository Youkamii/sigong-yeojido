# 한성부 도읍 조형 수정 #114

1500년 도읍 장면에 서양식 돔 궁전이 쓰이는 것을 실제 화면에서 확인했다.
기존 Fantology 부품 조립기를 사용해 넓은 처마·겹지붕·목조 기둥의 건물과
굴뚝을 제거한 어두운 지붕 가옥을 추가했다. 1876년 이전 palace/house 선택에 적용한다.
원본 생성기와 원본 조형을 유지하며 근현대 전용 건물 분기는 그대로다.
건물 외형은 상징 모형이며 개별 궁궐의 실제 모습이나 배치를 복원했다고 주장하지 않는다.

[1500년 실제 화면](hanseong-building-114.png).

포함한 [세계 탐색 29개 검사](building-scenes-114.json) 통과. 브라우저 오류 없음.
