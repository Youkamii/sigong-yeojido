# 그래프 전체에서 연도 차이 찾기 (#53, Q5)

비교 화면의 ‘연도 차이 자동 찾기’는 저장된 사례 목록에 의존하지 않는다.
`/api/comparison-differences`가 실제 RDF의 `sameEventAs` 연결, 서로 다른 사료의 사건 날짜,
선택한 직접 연도·환산 Claim을 조회한다. 각 연도 값이 다른 쌍을 페이지 단위로 돌려준다.
`sourceA`·`sourceB` 인자로 삼국사기/일본서기처럼 두 원사료만 지정할 수도 있다.
사료·AI 필터는 사건 연결·양쪽 날짜·양쪽 환산 근거 모두에 적용한다.

실제 전체 사료 선택에서 백제 건국과 아신왕/아화왕 사망 2쌍을 찾았다.
삼국사기/일본서기로 제한하면 후자 1쌍이다. 환산 근거를 빼거나 AI를 제외하면 결과가 없다.
1개씩 페이지 이동, 원문·환산 방식·추론 한계 표시, 사료 변경 후 이전 버튼·결과 제거가 통과했다.
`scripts/verify_comparison_discovery.py`와 `comparison-discovery-53-local.json`에 실행 증거가 있다.

988개 Source 선택을 다중 VALUES 결합으로 반복하던 첫 구현은 느려서 브라우저 검사가 실패했다.
실제 Claim을 가진 Source와 선택 목록의 교집합을 구하고, 결합을 늘리지 않는 IN 필터로 바꿨다.
같은 전체 선택 검사를 다시 통과했다. 선택하지 않은 사료를 추가하는 최적화는 하지 않는다.

직접 연결이 없는 사건, 환산 연도가 없는 문면 차이, 불확실한 범위만 있는 날짜는 자동 차이 목록에 넣지 않는다.
연도 값이 다르다고 실제 역사 사건의 정답을 고르지 않는다. 알려진 사례 목록에서는 환산이 없는 사비 천도 원표기도 계속 비교할 수 있다.
