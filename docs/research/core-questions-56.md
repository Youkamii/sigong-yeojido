# Q1~Q9 실제 수록 자료 검사 (#56)

`scripts/verify_core_questions.py`는 API와 실제 Fuseki를 함께 읽는다. Claim→chunk 인용 연결은
현재 모든 Claim에 대해 확인하며, 날짜·인물·동일성·사료 필터에는 실제 자료를 쓴다.
빈 결과는 그 조건의 응답 검사로만 세며 자료 확보 완료로 세지 않는다.

| 질문 | 이번 실제 검증 | 남는 범위 |
|---|---|---|
| Q1 삼국사기만·500년 지도 | 사료·기간에 맞는 40개 후보, 전체 해제 시 0 | 후보의 역사적 위치 확정을 뜻하지 않음 |
| Q2 백제 건국 연도 | 사료별 원표기 3개, 환산 -18/-17, 鴻佳는 미환산 | 기관·학술 역법표 독립 대조 |
| Q3 기간·신라 소속 인물 | 지증왕·법흥왕·진흥왕의 재위·소속, 빈 시대 검사 | 당시 모든 인물의 수집, 생몰 전체와 재위 구별 |
| Q4 주장 근거 | Claim 260개·인용 chunk 177개 전부 원문·Source 일치 | 사람의 역사 해석 검토와 구별 |
| Q5 삼국사기·일본서기 연도 차이 | 그래프 자동 검색으로 사망 사건 1쌍, 405/285와 서로 다른 환산 방식 | 직접 사건 연결·숫자 연도가 없는 기록은 자동 검출 밖 |
| Q6 한사군 위치와 근거 | 네 군의 지역 견해·수록 후보·출처·직접 근거 여부를 집계 | **부분**. 진번 등의 좌표 미상, 현대 대표점과 고대 군치를 구별하며 옛 후보의 직접 근거도 보완 필요 |
| Q7 AI 연결 제외 | 그래프·시간·인물·역사 지도·위치·비교에서 human 결과 0 | 현재 사람 작성 Claim 0. 원문 열람과는 다른 필터 |
| Q8 사료 시간 두 가지 | 삼국사기 편찬 1145, 다루는 기간 -57~935 | 미상 Source의 값을 추정하지 않음 |
| Q9 같은 사람이라는 근거 | 삼맥종/심맥부 직접 설명, Person 2개와 동일성 Claim 유지 | 자동 병합 없음 |

현재 검증은 **8개 PASS, Q6 PARTIAL**이다. 이는 수록한 범위의 질의 수용 결과이며 역사 자료의 완전성을 뜻하지 않는다.
별도 브라우저 검사 `verify_people.py`, `verify_time.py`, `verify_comparisons.py`, `verify_comparison_discovery.py`,
`verify_location_filters.py`, `verify_historical_map.py`가 실제 표시·원문 이동·필터 변경을 확인한다.
실행 JSON의 실제 Source·chunk·Claim 수를 기준으로 삼는다. 뒤 조사로 데이터가 늘면 이 스크립트를 다시 실행한다.
