# 북한 작성·유엔 배포 국가보고서 발췌 (#66)

문서 A/HRC/WG.6/33/PRK/1의 공식 영문 PDF 15쪽을 실제로 내려받아 인용을 대조했다.
351,660바이트, SHA256 `1c558a38be2293ad67280e02e748f3185fc10ead1dace580f7a681d582ad13a5`.
Claude Opus 5 / max가 조사했고 Codex가 PDF 텍스트에서 공백만 무시해 각 인용의 페이지와 일치를 확인했다.

북한이 작성한 본문, 유엔이 붙인 표제면 배포 날짜와 각주를 구별했다. Source 1개, chunk 4개,
Claim 3개다. 제재에 관한 북한 보고서의 표현, 헌법 166조 언급, 유엔 배포 날짜를 각각 수록했다.
유엔이 보고 내용을 승인한 것으로 쓰지 않는다. 각주의 세 단어만으로 작성자를 입증한다는 초안 Claim은 채택하지 않았다.
작성자와 배포자 정보는 국가보고서의 서지에 남겼다.

인용 밖 일방 제재·조문 내용은 보충하지 않았다. 2019-02-20은 북한의 작성·제출일이나 실제 심의일이 아닌
유엔 문서 배포 날짜다. 기존 위키문헌 헌법의 개정 판본 미확정 상태는 그대로다.
영문 짧은 인용 21단어와 날짜 필드 3단어만 수록했고 PDF 전문·조선어 번역본은 Git에 넣지 않았다.

`dprk-upr-report-66.json`에 공식 URL·원본 해시·각 인용 페이지·추출기 버전·모델 실행 기록을 남겼다.
사람의 해석 검토와 공식문서 전문의 재배포 조건 확인은 미완료다. 재현 스크립트 `import_dprk_upr.py`는 PyMuPDF를 사용하며 뷰어 실행에는 필요 없다.
