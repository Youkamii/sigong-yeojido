# 사건 내용에 따른 장면

- #131: 우륵 음악 전습은 현악기와 실제 현장 인물 4명으로 구성한다. 계고는 악기 앞, 법지는 노래, 만덕은 움직이는 자리로 나뉜다.
- 김만덕 구휼은 곡식·수레·분배 장면을 쓴다. 기존 일반 군중과 관청 대신 활동을 보여주며, 확인되지 않은 포구·난파선을 더하지 않는다.
- 울산공업센터 기공식은 첫 삽 모형을 쓴다. 완성된 공장이나 근거 없는 참석 인물을 만들지 않는다.
- 고리 공사는 기존 근거의 착공~준공 연도를 사용한다. 준공 전에는 골조, 준공 연도에는 발전 시설을 뜻하는 건물로 전환한다.

악기 현의 표시 수, 자루 수, 익명 인물, 삽·골조·건물은 활동을 알아보기 위한 상징 모형이다. 출토품 복원, 실제 건물 외형·수량·현장 배치의 재현이 아니다. 기존 사건·연도·장소·실명 인물·효과 근거를 그대로 사용한다.

`scripts/add_activity_assets.py`로 조형 5종을 재생성한다. 원래 Fantology 생성기는 변경하지 않는다.
`scripts/verify_activity_scenes.py`는 실제 API에서 다섯 연도를 열어 조형·현장 인물·완공 전후·선택 확대·브라우저 오류를 확인한다.
