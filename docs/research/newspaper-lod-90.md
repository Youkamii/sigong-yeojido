# 독립신문 공개 다운로드 수집과 공개 적재 대기 (#90, #52)

독립신문(서재필)의 제공본 19,635개 기사를 실제로 수집·추출·검사하고 c2에 보관했다.
공개 뷰어에 적재한 기사는 **0개**다. Source·chunk·Claim의 운영 집계에는 더하지 않는다.
원 이미지와 현대어 표기문의 공개 제공도 실행하지 않았다. #90은 부분 상태다.

## 실제 파일과 추출

[신문별 자료 화면](https://nl.go.kr/newspaper/news_release.do)의 선택 응답과 JavaScript가 만드는
다운로드 링크로 ZIP 11,520,623바이트를 받았다. 그 안의 `독립신문(서재필).ttl`은
60,103,001바이트·739,883트리플이다. 이것은 수집한 원 RDF의 수이며 운영 Fuseki 집계가 아니다.

| 항목 | 실제 확인 |
|---|---|
| 기사 | 19,635건, 중복 ID 0 |
| 발행일 | 776개, 1896-04-07~1899-12-04 |

| 원문/현대어 경계 | `번역문 :` 19,601건·잘린 `문 :` 34건. 원문 접두사가 없는 1건도 보존 |
| 옛한글 PUA | 원문 기사 19,405건에 존재. 치환·정규화·공백 제거 없음 |

| 공개 원문·새 주장 | 0건·0개 |

추출기는 원문을 원 `abstract` 문자열의 정확한 부분으로 저장하고, 원문 경계·원 전체 문자열의 해시·
제공자의 현대어 부분 길이와 해시를 남긴다. 제공자 현대어 본문은 추출 JSONL에 넣지 않았다.
원본 ZIP에는 두 글이 함께 있으며 별도 작업 폴더에 보관한다.
발행일은 숫자 원표기를 유지하면서 형식만 `YYYY-MM-DD`로 바꾼다. 사건 발생일이나 역법 환산으로 쓰지 않는다.

RDF 파서와 별도로 만든 원 Turtle 문자열 검사가 **19,635건 전체의 원문·날짜·해시를 대조해 실패 0개**였다.
추출을 반복한 `chunks.jsonl`과 `extraction.json`도 바이트가 같았다.
최종 추출기는 기존 `services/ttl_check.py`를 사용하며 표준 라이브러리만 필요하다.
별도 rdflib 7.6.0으로 만든 최초 결과와 기존 파서의 결과도 두 파일 모두 바이트가 같았다.
최초 c2 실행은 rdflib 미설치로 실패했다. 의존성을 추가하지 않고 기존 파서를 사용하도록 바꾼 뒤
c2에서 21.45초·최대 메모리 약 694MiB로 재추출했고, 두 출력 파일이 로컬·보관본과 일치했다.
같은 c2에서 19,635건 전체의 별도 문자열 검사도 통과했다.

공개 날짜 검색의 1896-07-14 기사 28개는 ZIP의 같은 날짜 28개와 ID가 모두 같았다.
본문은 8건이 달랐다. 현재 웹 문자열로 과거 다운로드본을 덮어쓰지 않는다.
온라인 신문 목록은 19,636건, ZIP은 19,635건이다. 연도 집계의 차이는 1897년에 있으며 원인은 미확인이다.
[ID·본문 차이와 잘린 구분자 목록](../../data/research/nl-dokrip-private-90/text-audit-summary.json)

원 MODS XML에서 `licenseType` 값 `0`과 권·부 원표기 `Ⅰ043`을 확인했다.
코드 `0`을 공공누리 제0유형이나 CC0로 해석하지 않았다.
원소장처·제공자의 수정 시각·신문의 발행일은 서로 다른 필드로 보존한다.
검색 전거의 중추원(고려)·감정어 정서 같은 오분류를 역사 엔티티로 승격하지 않았다.

## 공개 적재가 남은 이유

[아카이브 안내](https://nl.go.kr/newspaper/introduce.do)는 고신문의 저작권 만료와 이미지 출처 표시 후 자유 이용을 안내한다.
범용 Copyright 푸터나 원소장처 이름만으로 이 개별 이미지 안내를 부정하지 않는다.
다만 신문별 LOD의 기사 전사·현대어 표기문에 적용되는 제공 조건은 아직 연결하지 못했다.

추가로 확인한 [기관 저작권정책](https://www.nl.go.kr/NL/contents/N70600000000.do)은 다음과 같이 안내한다.

> 공공누리가 부착되지 않은 자료들을 이용하고자 할 경우에는 공공저작물 관리책임관 및 담당자와 사전에 협의한 이후에 이용하여 주시기 바랍니다.

국가서지 LOD의 [공공데이터포털 자료](https://www.data.go.kr/data/15083378/fileData.do)는 제1유형이고,
소장자료·서지 API 두 건은 이용 범위 제한이 없다고 표시한다.
그러나 각 목록의 범위가 이 신문별 전사·현대어 ZIP까지 포함한다는 근거는 확보하지 못했다.
다른 API의 조건을 그대로 붙이지 않는다. 이는 불허가 확인됐다는 뜻도 아니다.

`viewer.nl.go.kr`은 robots 전면 차단이므로 이미지 요청 0건이다.
`lod.nl.go.kr`의 라이선스 리소스 역시 제한되어 정의를 읽지 못했다.
`www.data.go.kr`의 열거된 제한은 Googlebot 그룹에 속한다. 조사자의 보고서가 기관 목록 미열람을
일반 접근 금지처럼 적은 부분은 이 범위로 정정한다. 실제 읽은 세 상세 페이지의 조건과 적용 범위 판단은 별도로 남긴다.

[문의 초안](nl-newspaper-inquiry-90.md)은 미발송이다. 확인 회신을 받으면 Source 카드·원문을 공개 적재하고
실제 서비스의 검색·연도·근거 화면을 검사해야 한다. 이 운영 수용은 **NOT_RUN**이다.
