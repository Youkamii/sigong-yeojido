# 사건 관련 장소와 기관 좌표 (#81)

국가유산청 목록의 5곳을 사건 근거·기준연도·현재 목록 좌표로 나눠 연결했다.
Source 6개, chunk 13개, Claim 15개와 Place·Event 각각 5개를 추가했다.
화면의 **사건 · 국가유산청 장소** 렌즈와 **사건 관련 장소** 지도 종류에서 볼 수 있다.

| 기준연도 | 기관 목록의 장소 | 좌표의 성격 |
|---:|---|---|
| 1270 | 진도 용장성 | 성곽·궁궐 터의 현재 목록 좌표 |
| 1593 | 고양 행주산성 | 산성과 후대 기념시설을 포함하는 장소의 목록 좌표 |
| 1636 | 남한산성 | 산성 지정구역의 목록 좌표 |
| 1919 | 화성 제암리 3·1운동 순국 유적 | 예배당 터와 후대 기념시설의 목록 좌표 |
| 1980 | 광주 구 전라남도청 | 등록 대상인 구 본관의 목록 좌표 |

사건의 관련 장소는 `hasEventSite`, 그 장소의 현재 좌표는 `locatedAt`, 기록이 명시한
기준연도는 `hasReferenceDate`로 구분한다. 좌표를 전투 범위나 정확한 교전 지점으로 쓰지 않는다.
1270은 기관 해설이 적은 고려의 항복 연도이며 용장성 항쟁 전체의 시작·종료를 뜻하지 않는다.
제암리의 1919년 4월 15일은 대한민국역사박물관의 직접 날짜 인용을 따로 연결했다.
해당 사건을 표시하려면 국가유산청과 박물관 자료가 모두 선택되어 있어야 한다.

API가 제공한 경도·위도 문자열과 지정 면적을 원 레코드에 보존했다. 공식 안내는 경도·위도와
미제공 값 0을 설명하지만, 기준계·위치 오차·대표점 선정 방법을 밝히지 않는다.
이를 WGS84 확인값이나 유적의 실측점으로 승격하지 않는다. 지도는 제공 숫자를 그대로 표시한다.
지정 면적을 사건의 공간 범위로 바꾸거나 없는 도형을 만들지 않았다.

Claude Opus 5 / Max 조사는 세션 한도로 오류 종료했다. 저장된 초안은 원 API 응답과 해설을
대조한 뒤 사용했으며 [원 호출 기록](../../data/research/khs-events-81/run.json)의 실패 상태를 유지한다.
초안의 두 오류를 수정했다. 제암리 해설에는 1982가 있지만 사건 연도 1919는 없다.
구 전남도청은 본문 건립연도 1930과 시대 필드 1925가 달라 두 값을 구별했다.
[응답 해시·정정 기록](khs-events-81.json)에 직접 대조한 내용을 남겼다.

원문은 구조화 사실과 페이지별 25단어 이내의 짧은 해설만 수록했다. API 본문·이미지 전체의
재배포 권리를 확인한 것으로 세지 않는다. 조사와 호출은 창 없이 실행했고 기관에는 연락하지 않았다.

[재현 검사](khs-events-81-repeat.json)에서 새 파일 38개는 두 실행 및 저장소 파일과 바이트가 같다.
전체 Claim 9,416개 검증은 실패·경고 0개, TTL은 244,954 트리플이다.
실제 화면 검사는 API의 원 좌표·사건/날짜 인용, Event→Place 그래프, 2D 표시,
3D 점 도형, 연표 이동, 사료·AI 필터, 다른 지도 종류 전환과 480px 화면을 대상으로 한다.
