# 국편 문의 창구 확인 (#12)

국사편찬위원회 **연구편찬정보화실의 공개 업무 전화는 02-500-8387**이다.
공공데이터포털의 [삼국사기](https://www.data.go.kr/data/15053635/fileData.do),
[고려사절요](https://www.data.go.kr/data/15115521/fileData.do),
[한국독립운동사자료](https://www.data.go.kr/data/15115618/fileData.do) 원 HTML 세 건의 관리부서·전화번호가 일치했다.
로그인 없이 받은 HTML의 `telNo = "025008387"`과 페이지의 번호 표시 규칙을 대조했다.

[원 HTML·해시](../../data/research/nikh-contact-12/html-archive.json),
[Claude Opus 5 / max 결과](../../data/research/nikh-contact-12/result.json),
[정상 종료 기록](../../data/research/nikh-contact-12/run.json)을 남겼다. 이 호출은 기존 초안과 공식 HTML을 작업 폴더 안에서 읽었으며 파일 접근 거절이 없었다.

국편의 서면 접수 이메일은 확인하지 못했다. `opendata_help@nia.or.kr`·1566-0025는 NIA 포털 운영 창구다.
공공데이터 제공신청은 새로운 자료를 신청하는 별도 절차이며 실제 신청서는 로그인이 필요하다.
날짜·글자 코드와 기존 공개 파일의 이용조건 문의를 그 신청서로 대신 보내지 않았다.

[날짜·글자 문의 초안](nikh-inquiry-draft.md)과 [이용조건 문의 초안](nikh-license-inquiry-12.md)은 준비됐으나 **전화·서면 모두 미발송**이다.
담당 부서에 서면 접수 경로를 확인하고 회신을 받아야 공식 정의와 이용조건의 남은 부분을 확정할 수 있다.
