# 한사군 위치 견해 보완 (#49)

Claude Opus 5 / Max effort 조사 결과에서 백과사전 4항목·GeoNames 레코드 1개,
chunk 10개·Claim 9개를 반영했다. 진번·임둔을 새로 넣고 낙랑·현도의 지역 서술을 추가했다.
서로 다른 사료의 같은 이름은 자동 병합하지 않는다.

진번재대방설의 인용은 옛 진번군 남부 강역에 관한 것이므로 별도 장소로 뒀다.
현도군 인용은 HTML의 `老城`을 보존했다. 조사 초안의 `老城`과 같은 글자로 정규화하지 않았다.
임둔의 두 위치 견해는 서로 다른 대상으로 남아 충돌 1개를 더 표시한다.

함경남도는 GeoNames 1877450의 실제 HTML 십진 좌표를 레코드로 옮겼다.
이 현대 대표점과 임둔 비정의 출처를 함께 켰을 때만 보조점을 그린다.
`grounded=false`인 지역 대표점이며, 고대 군치 좌표나 행정 경계가 아니다.
재령읍과 재령평야의 동일성을 확인하지 못했으므로 진번에 재령읍 점을 붙이지 않았다.
나머지 견해의 좌표·자료에 없는 유효기간도 미상으로 남았다.
