# 중국 동부·만주·일본 연결 #113

저장된 Natural Earth 육지 자료를 경도 115~146, 위도 25~49 범위로 잘라 85개 조각으로 연결했다.
한반도 윤곽·74,182면 지형·좌표 투영과 8배 크기를 유지한다. 지도 첫 화면은 기존 시대 장면이며
`주변국까지`로 범위를 넓히거나 드래그해 주변 육지를 탐색한다. 현대 국가 경계를 과거 국경으로 표시하지 않는다.
좌표의 투영 기준과 탐색 범위를 분리했고, 카메라 거리별 깊이 정밀도·안개·그림자 범위를 확장했다.

[실제 화면 검사](neighbor-world-113.json) · [주변국 화면](neighbor-world-113.png).
중국 동부·만주·규슈·혼슈·홋카이도, 한일 사이 바다, 실제 드래그 이동, 한반도 전체와 독도,
모바일, 1909년 하얼빈역과 안중근·이토 히로부미의 당시 활동 배치가 통과했다.
하얼빈 좌표는 기존 조사 기록 그대로이며 ‘캔버스 밖’이라는 오래된 표시 설명만 수정했다.
JS 좌표·조형·해안선 검사와 Python unittest 116개도 통과했다.

같은 PC/RTX 3060/1920×1080 medium 재측정에서 초기 준비 7.703초,
정지/드래그/한반도 전체 RAF 162.1/162.9/146.2 FPS였다. 네트워크와 기기별로 달라진다.
주변 육지는 낮은 상세도의 지리 배경이며 주변국 역사 전체나 지구 전체를 구현한 것은 아니다.
