# 한국독립운동사자료 공개 배포본 수집 (#77)

[공공데이터포털 15115618](https://www.data.go.kr/data/15115618/fileData.do)의 공개 ZIP을 받았다.
2026-09-07 확인한 이용조건은 공공누리 제1유형(출처표시)이다. ZIP은 13,394,893바이트다.
안내는 43책이지만 **실제 XML은 42개이며 36권이 빠져 있다.** 누락 권을 만들어 채우지 않았다.

자료집의 권별로 Source 42개를 만들었다. 본문 단위는 13,366개로 기사 13,266개,
절 20개, 현대 서문·범례·해제·화보 안내 80개다. 빈 본문 287개도 보존했다.
텍스트가 없는 이미지 항목과 서문만 있는 권을 전문 확보로 표시하지 않는다.
자료집 간행일은 원 문서 작성일과 구분하며, 한글·한문·일문이 섞인 배포본에 새 번역을 붙이지 않았다.

문답 표지·인명·도장·비점·하첨자·번호의 글자를 보존하고 XML 속성과 본문 위치를 별도 필드에 남긴다.
교감주 안의 문답 표지 위치도 확인했다. 본문 태그 미처리 0개다.
`0000-01-10 / 一月十日` 1건은 원값을 보존하지만 서기 0년으로 색인하지 않는다.
일자 코드가 있는 항목들의 연도 범위는 1910~1955로, 안내의 전체 대상 시기와 다르다.

두 번 추출한 JSONL 126개의 바이트·SHA256이 일치한다. XML 본문 ID와 기사/절 구분은 전량 대조했고
누락·중복은 0개다. 추출기 7개 검사, 서버 17개 검사가 통과했다.
[다운로드·권별 수치·원 서지·빈 본문·해시](independence-77.json). 실제 운영 화면·검색은 다음 배포에서 검사한다.

조사는 Claude Opus 5 / Max의 저장 결과를 사용했다. 원 호출은 세션 한도로 오류 종료했고,
공개 파일 다운로드·내용 검증·추출은 Codex가 수행했다. 원문과 JSONL은 Git에서 재현할 수 있다.

```sh
python scripts/fetch_datago_bulk.py --dataset 15115618
python services/ingestion/import_public_nikh.py --source korean-independence --bulk data/bulk/15115618.zip --download-meta data/bulk/15115618.meta.json --out data/sources --report docs/research/independence-77.json
```
