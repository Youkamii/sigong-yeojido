# 전체 시대에 이어지는 생활 배경 (#166)

[공개 화면](https://sigong.rabbion.info/) · [이슈 #166](https://github.com/Youkamii/sigong-yeojido/issues/166)

기존 화면은 작은 마을 수십 곳과 기간이 한정된 도시 장면만 표시해 전체 한반도에서 대부분 빈 땅으로 보였다. 1960년은 사용자가 보낸 비교 화면이며, 수정 범위는 전체 시간선이다. 기존 #162·163의 객체 수와 기능 검사만으로 화면 밀도가 충분하다고 판단했던 것을 바로잡았다.

## 구현

- 실제 지도 지형에서 해안·경사를 검사한 익명 생활권 102곳을 계획한다. 북부·중부·남부와 제주에 분포하며, 역사 장면과 겹치는 생활권은 해당 장면이 표시되는 동안 제외한다.
- 선사 정착, 초기 농경, 삼국, 고려, 조선, 조선 말, 개항기, 일제강점기, 초기 현대 농촌, 지붕 변화, 현대의 11개 외형 기간에 맞춰 집과 밭을 표시한다. 같은 외형 기간과 점유 상태에서는 전체 지도 모델을 재사용한다. 상세 모델은 현재 보고 있는 곳에 따라 최대 4곳을 보관한다.
- 길을 따른 마을, 모여 있는 취락, 장터 주변 블록, 길게 놓인 밭의 네 가지 배치를 섞는다. 반복되는 원형 밭을 없애고 집과 밭이 겹치지 않게 배치한다. 밭에는 고랑을 넣는다.
- 전체 지도는 간단한 지붕·벽·밭·길을 지역별로 합쳐 그린다. 가까운 상세 모델은 최대 4개 생활권, 생활권당 20채만 만든다. 실제 모델 크기를 한 번 측정해 확대 전후의 집 크기를 맞춘다.
- 익명 생활 배경은 사실을 증명하는 장소·사건·인물·출처 선택 대상에 넣지 않는다. 집의 개수와 배치는 인구 통계나 옛 마을 평면을 복원한 결과가 아니다.

개발은 Astra low 하위 에이전트의 별도 branch/worktree에서 수행하고, 총괄이 통합·화면 검토·배포를 담당했다. 지형·해안선·강·카메라·지도 크기·역사 자료 파일은 이번 변경에 포함하지 않았다.

## 검사

단위 검사 10개와 기존 시대별 풍경·건물·인물 검사 3개가 통과했다. 실제 모델 크기 검사는 7개 시대의 3개 변형을 비교했다. 원거리 모델의 중복 숨김·복원과 기존 모델의 기본 회전도 검사했다.

실제 API와 로컬 프런트로 동작 검사 13개가 통과했다. 1100→1101년에는 점유 상태가 같고 전체 지도 객체가 유지됐다. 이 과정에서 가까운 상세 모델의 누적 생성 수는 9→14로 늘었으므로 모든 상세 모델의 무재생성을 검증했다고 표현하지 않는다. 시대 경계 교체·기존 객체 해제, 시험용 점유 영역 제외·복원, 지붕 중복 방지, 표시 설정, 실제 역사 이야기·인물 이동, 익명 풍경과 사실 선택 대상의 분리를 확인했다.

화면 검사는 실제 공개 API와 로컬 프런트를 연결해 시작했다. 첫 수정본의 원형 도장 같은 밭, 겹친 지붕, 확대할 때 작아지는 집을 직접 확인하고 수정했다. 객체 개수만으로 시각 검사를 통과시키지 않았다.

재실행 가능한 검사:

```text
node --test tests/settlement-regions.test.mjs tests/scenery-overview.test.mjs tests/scenery-detail.test.mjs
node scripts/test_scenery_period.mjs
node scripts/test_period_buildings.mjs
node scripts/test_period_figures.mjs
python scripts/verify_inhabited_scenery.py --out <결과 폴더>
python scripts/verify_inhabited_interactions.py --out <결과 폴더>
```

브라우저 검사는 Chrome과 Python Playwright를 사용하며 창을 표시하지 않는다. `--frontend services/host`를 붙이면 프런트 파일만 로컬에서 읽고 역사 데이터는 실제 공개 API를 사용한다. 인물·사건의 실제 검색과 이동은 동작 검사에 포함한다.

## 범위와 남은 한계

생활 배경의 확대 작업이다. 출처 있는 역사 사건 추가 수집, 정확한 옛 도시 구획, 북쪽의 현대 건축 변화는 이번 결과로 완료 처리하지 않는다. 가까운 상세 모델과 먼 거리 간단 모델에는 색감과 벽 표현 차이가 남는다. 저사양 실제 기기 검사는 NOT_RUN이며 GitHub workflow는 0개다.
