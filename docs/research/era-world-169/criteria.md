# 시대별 모델링 평가 기준

이 문서는 #169의 평가 기준이다. 구현 완료 기록이 아니다. 기준 코드는 `7312de21`이며, 총괄이 공개 주소에서 같은 지역의 카메라를 고정해 31개 연도·114개 장면을 확보했다. 시대별 검토자 6명과 각각의 적대 검토자 6명은 모두 Astra max를 사용한다.

## 무엇을 평가하는가

| 축 | 확인할 내용 |
|---|---|
| 시대의 구별 | 지붕 색과 개수 외에 주거 구조·건축 재료·가로·생산·이동 수단·복식이 구별되는가. 전국이 같은 해 한꺼번에 같은 모습으로 바뀌지는 않는가. |
| 지역의 구별 | 북부·서해·동해·남부·제주의 생활과 도시 조건이 구별되는가. 수도의 양식을 모든 지역에 복사하거나 한 나라의 양식을 모든 문화권에 적용하지 않는가. |
| 정착과 도시 | 작은 취락·읍성·장터·행정 중심지·수도·근대 항구·공업도시·현대 도시의 공간 구성과 주변 생활권을 구분하는가. |
| 생업과 일상 | 경작·저장·어로·목축·채집·제작·운송·교환·돌봄·교육·신앙·여가 등 그곳에 사는 이유가 읽히는가. 단순히 인물을 세워 놓는 것으로 대체하지 않는가. |
| 권력·신앙·장례 | 관부·성곽·궁궐·사찰·탑·제의·무덤 등이 시대·지역·기능에 맞는가. 알려진 시설의 핵심 형태를 다른 시설과 같은 부품 조합으로 바꾸지 않는가. |
| 교통과 생산망 | 길·나루·항구·배·역·철도·도로·공장·창고 등이 서로 이어지는 장소의 역할을 보여주는가. 실측 노선과 추정 풍경은 구별하는가. |
| 사람과 관계 | 복식·도구·자세·규모가 역할과 시기에 맞는가. 후원·서신·전승·문헌의 인물과 실제 현장 참여를 혼동하지 않는가. |
| 사건의 성격 | 건설·생산·구휼·피난·학살·항쟁·전쟁·의례·교역·재난을 같은 병사 격자나 책상으로 처리하지 않는가. 평범한 삶이 사건 때문에 지도에서 사라지지 않는가. |
| 시간의 연속성 | 시설 건립 사건이 끝나도 시설이 남는가. 행정 이름이나 지위가 바뀌어도 도시 자체를 제거하지 않는가. 폐허·이전·재건·성장과 같은 변화가 구분되는가. |
| 공간과 크기 | 같은 집이 확대 전후 같은 주거형인가. 사건 때문에 주변 도시 크기가 달라지지 않는가. 섬·산·물길과 건물·성벽·도로가 공존 가능한 크기와 위치인가. |
| 자료와 추정 | 출처 있는 사건·실제 위치·발굴 평면·복원안·이름 없는 생활 배경을 구분하는가. 자료 부재를 역사적 부재로 단정하지 않는가. |
| 사용성과 성능 | 전체·지역·거리 확대를 오가며 장소를 이해할 수 있는가. 같은 표시 기간의 구조는 유지하고 가까운 곳의 상세 모델만 제한해서 만들 수 있는가. |

## 적대 검토자가 반박할 사항

1. 캡처에 보이지 않는 것을 코드·데이터 전체에 없다고 단정했는가.
2. 일반 카메라 중심점을 정확한 옛 도시나 사건의 위치 근거로 삼았는가.
3. 모델 카탈로그에 있는 것과 실제 장면에서 생성되는 것을 혼동했는가.
4. 저장된 모델 목록을 현재 보이는 모델로 오해했는가.
5. 평지 대역 실행을 실제 지형·공개 화면 검증으로 보고했는가.
6. 하나의 기관 설명이나 출토 사례를 전국·전 시대의 규칙으로 확대했는가.
7. 서로 다른 역사적 시간 범위를 한 시점으로 압축했는가.
8. 도식적인 3D 지도에 불필요한 실사 복원·실측 정확도를 요구했는가.
9. 동일 격자·단순화 자체를 무조건 오류라고 하거나, 새 템플릿을 반복하는 해결책만 제안했는가.
10. 수정으로 다른 지역의 규모·자료 신뢰도·연속성·성능을 훼손할 수 있는가.

반박은 찬성·수정·기각·미검증으로 나누고 근거를 붙인다. 반박 개수를 채우기 위해 오류를 만들어내지 않는다. 합의되지 않은 내용은 총괄이 근거와 실제 장면을 대조해 남기거나 제외한다.

## 수정에서 분리해야 하는 기간

| 대상 | 원하는 표시 규칙 |
|---|---|
| 지역·생활권 | 특정 사건 유무와 독립해 존재하며, 확인된 변화 또는 추정 배경의 변화에 맞춰 갱신한다. |
| 이름·행정 지위·수도 역할 | 해당 속성의 유효기간에만 적용한다. 속성 종료를 지역 소멸로 취급하지 않는다. |
| 시설 | 건립·사용·변형·훼손·폐허·복구를 구분한다. 건립 사건의 종료와 시설 수명을 분리한다. |
| 사건 | 그 기간에 해당 장소의 일부를 변화시킨다. 주변 도시와 생활 배경 전체를 지우거나 축소하지 않는다. |
| 인물 | 생존 기간만으로 배치하지 않고 그 시기 그 장소와의 관계를 확인한다. 현장 참여가 확인되지 않으면 그렇게 표시하지 않는다. |
| 풍경·미술 표현 | 사료로 입증된 개별 사실을 사칭하지 않으면서 시대·지역·생활 조건에 맞게 구성한다. |

이름 없는 생활 배경에 모든 집의 사료를 요구하지 않는다. 반대로 특정 시설·인물·사건의 이름을 붙였으면 그 이름의 핵심 의미를 모형과 위치·기간이 훼손하지 않아야 한다.

## 검사를 통과했다고 할 수 있는 조건

- 건립 연도와 다음 연도, 사건 중과 이후, 이름·지위 변경 전후를 같은 카메라로 비교한다.
- 수도뿐 아니라 지방 도시·생산 또는 교역 지역·농어촌·북부·섬을 직접 확인한다.
- 멀리서 시대와 장소의 성격이 읽히고, 가까이서 형태·규모·생활 요소가 이어지는지 본다.
- 오류 없는 실행, 객체 수 증가, 프레임 수만으로 시각적·역사적 적합성을 통과시키지 않는다.
- 역사적 근거가 부족한 권고는 필요한 추가 조사와 표현 가능한 추정 범위를 명시한다.
