# 평가 결과를 실제 세계로 바꾸는 수정 기준

이 문서는 #169의 구현 지침이다. 아래 기능은 아직 구현하지 않았다. 기준 코드는 `7312de21`이다. 개별 사실과 반박 결과는 [종합 평가](REPORT.md), 세부 근거는 시대별 보고서를 따른다.

## 먼저 고쳐야 하는 연결

현재는 사건 한 건이 건물·도시·주민을 함께 만드는 경우가 많다. 그래서 준공 사건이 끝나면 시설도 사라지고, 같은 위치에 새 사건이 들어오면 기존 도시를 줄이며, 사건의 큰 원형 점유 범위가 주변 생활권을 제거한다. 이 상태에서 에셋을 추가하면 사건이 있는 해에만 커다란 모형이 생겼다가 사라지는 현상을 확대한다.

다음 대상을 분리하되, 기존 기간 필터와 객체 재사용 구조를 활용한다. 모든 연도에 세계를 새로 만드는 방식은 필요하지 않다.

| 대상 | 유지할 것 | 바뀌는 것 | 확인 방법 |
|---|---|---|---|
| 생활권·도시 | 장소의 중심과 주거·생산·길의 연결 | 확인된 성장·이전·축소·소멸, 지역별 풍경 단계 | 사건 전후에도 같은 중심과 생활 관계가 이어지는지 비교 |
| 이름·지위 | 장소 자체 | 명칭, 수도·행정 중심 역할, 표시 기간 | 제주시의 2005→2006, 한성의 이름·역할 변경을 분리 |
| 시설 | 사용 중인 건물과 기능 | 착공·준공·증축·훼손·폐허·재건·용도 변경 | 건립 연도와 다음 해, 알려진 전환 시점을 비교 |
| 사건 | 기존 장소와 관계 | 관련 구역의 활동·피해·참여자·일시 시설 | 사건 등장만으로 도시와 이웃 마을이 줄거나 사라지지 않는지 비교 |
| 사람 | 그 시기 그 장소와의 관계 | 실제 현장 참여, 역할, 자세, 도구 | 생존·후원·문헌 등장만으로 현장 참석을 주장하지 않는지 확인 |
| 이름 없는 풍경 | 시기·입지·생업에 맞는 생활 배경 | 건물·밭·작업·이동 수단의 조합 | 개별 집의 사료를 요구하지 않되 실제 유적으로 오인시키지 않는지 확인 |

시설의 종료 연도가 모호하면 무조건 한 해 뒤 없애거나 현재까지 보존했다고 단정하지 않는다. 확인된 사용 기간, 유적·폐허 표현, 추정 배경 중 자료가 뒷받침하는 상태를 택한다. 이름이 바뀌었다는 사실과 건물·도시가 사라졌다는 사실은 다르다.

## 넓은 지도를 채우는 단위

추가 단위는 집 한 종류의 복제가 아니라 **사람이 그곳에서 하는 일과 이어진 작은 생활 구역**이다. 집–작업장–저장–길, 장터–포구–창고–운송, 역–선로–화물장–상가처럼 서로의 존재 이유가 읽히게 구성한다. 같은 문화·기술을 공유하는 지역은 같은 부품을 쓸 수 있다. 부품을 공유하더라도 모든 도시에 같은 완성된 배치를 복사하지 않는다.

| 구역 | 필요한 관계와 변화 | 피할 대체 |
|---|---|---|
| 작은 취락 | 주거·취사·저장·물·생업·이웃 길, 입지에 따른 밀도와 평면 | 집 수와 지붕 색만 다른 군집 |
| 농업 지역 | 집과 경작지의 구분, 작업·저장·운반, 농법·도구 변화 | 전국에 같은 사각 밭, 밭을 가르는 충돌한 도로 |
| 어촌·하구·포구 | 물가 작업·어구·배·짐·건조/가공·저장·장터 | 육지 군집에 배 한 척 붙이기 |
| 제작·생산 지역 | 재료 유입·작업·연료/설비·완성품·폐기·반출 | 도자기·책·공장 이름만 있는 전시물 |
| 지방 중심지 | 관부·시장·주거·종교·길, 주변 취락과 기능 연결 | 축소한 수도 또는 확대된 마을 |
| 수도·대도시 | 중심 시설과 여러 생활 구역, 길의 위계·구역 간 이동 | 전각 하나와 동일한 3×3 주거 블록 |
| 근대 전환 도시 | 기존 도시와 새로운 교통·공업·제도·주거의 공존 | 모든 집을 같은 해 서양식·일본식으로 교체 |
| 현대 도시 | 구도심·저층 상가·다양한 주거·산업/서비스·교통·공공 공간 | 전부 빌딩숲 또는 지붕만 바뀐 농촌 |
| 사건 현장 | 사건 성격에 맞는 행위와 참여 관계, 전후 상태 | 학살·피난·항쟁·전투를 같은 병사 격자로 표시 |

이 구역을 매년 새로 복제할 필요는 없다. 확인된 변화 구간에서 구조를 갱신하고, 가까운 구역만 사람·도구·건물의 상세 모델을 표시한다. 멀어지면 같은 건물의 바닥·지붕 형태와 방향을 유지한 간단한 모델로 바꾼다. 카메라 거리 때문에 원뿔집이 맞배집으로 변하는 것은 단순화가 아니라 의미 변화다.

## 화면과 공간의 수정 기준

- 사건이 등장했다고 도시 전체의 크기를 바꾸지 않는다. 필요한 경우 사건의 활동 범위와 참여자 수·배치를 조절하고 기존 시설과 생활 구역의 일부에 얹는다.
- 섬보다 큰 장면, 물 위의 주거 블록, 산 전체를 덮는 도시를 지도의 전체 축소로 숨기지 않는다. 지역의 가용 지면·물길·경사와 건물/구역의 크기를 함께 맞춘다.
- 강·길·포구·경작지는 서로 이어져야 한다. 물길 데이터와 렌더링이 없는 상태에서 도시 안의 길만 늘리면 물류·생활 관계를 설명할 수 없다.
- 인물·문·배·도구는 함께 사용할 수 있는 비율로 맞춘다. 식별할 주인공은 표식·선택·카메라로 강조할 수 있으며 몸을 건물보다 거대하게 만드는 방식에 의존하지 않는다.
- 지도 전체, 지역, 가까운 생활 장면의 세 거리에서 같은 장소라는 인상이 이어져야 한다. 그림자·라벨 충돌·길의 연결도 이 세 거리에서 확인한다.

## 구현 순서와 통과 조건

1. **지속과 공존:** 건립 사건/시설, 이름/도시, 사건/생활권을 분리한다. 645→646 경주, 1240 강도, 1795 한성·제주, 1925→1926 경성역, 2005→2006→2020 제주를 같은 카메라로 비교한다. 현재 확보한 전후 화면과 추가 확인이 필요한 연도는 종합 보고서에 구분한다.
2. **잘못 전달하는 장면:** 현대 북부의 조선 건물 대체, 역·공항·철거·인쇄·종교 장면의 기본 모델 선택, 비구니 역할과 현장 참여, 민간 피해/피난/항쟁의 전투 대체를 고친다. 데이터의 의미를 명시적으로 전달하는 방법을 택하고 문자열 예외만 계속 늘리지 않는다.
3. **시대·지역·생활 묶음:** 위 묶음을 각 시대의 수도·지방 중심·생산/교역·농어촌·북부·섬에 맞게 연결한다. 실제로 같은 문화를 공유하는 지역까지 억지로 다르게 만들지는 않는다. 특정 왕조 교체 연도를 전국의 일괄 개축일로 쓰지 않는다.
4. **공간 연결과 거리별 표시:** 집·필지·길·강의 충돌과 단절, 섬과 도시의 크기, 원경/근경 형태 차이를 고친다. 큰 세계와 기존 이동·확대를 유지한다.
5. **실제 화면 재평가:** 같은 입력·카메라로 이전 오류가 사라졌는지, 다른 시대·지역과 성능이 나빠지지 않았는지 확인한다. 코드 검사·객체 수·프레임 수를 역사·시각 적합성 판정과 구분해 기록한다.

재사용 키에는 실제로 외형·구조를 바꾸는 지역·단계·용도·상태를 포함하고, 단지 연도가 한 해 바뀌었다는 이유로 모든 모델을 재생성하지 않는다. 원거리 모델 합치기와 가까운 상세 구역 제한은 유지할 수 있다. 지형과 수천 개 집의 면적 검사·배치를 매 프레임 반복하는 방식은 피한다. 성능 수치는 같은 장면·기기·설정에서 재측정하며 이번 평가에서 새로운 성능 합격 수치를 지어내지 않는다.
