독립 코드 발견은 다음과 같다.

1. **수도와 하위 활동이 같은 자리에서 경쟁한다.** `chronicle-assets.js:178-195`는 일반 사건을 생활 설정 앞에 두고 가까운 뒤쪽 장면을 compact로 만든다. `historical-regions.js:11-12`의 compact 도시는 전각 한 행만 반환한다. 직접 함수 호출에서 강화 전체 배치 목록은 140행, compact는 전각 1행이었다. 이는 생성 전 목록 수이며 실제 육지에 남은 모델 수가 아니다. 강화 판각과 수도 데이터의 지역점은 사실상 같다.
2. **전국 연도 설정이 지역 선택을 대체한다.** `period-buildings.js:4-17`은 연도와 seed로만 외형군을 정한다. 개경·평양·제주를 넣어도 같은 seed의 1240년 집은 모두 `era_goryeo_house_2`다. `scenery-period.js:8`은 이 구간의 배경 대표연도를 1200으로 고정한다.
3. **후원 관계가 작업 동작으로 바뀐다.** 묘덕은 `history-scenes.json:3784-3792`에서 on-site이며, `chronicle-event-scenes.js:324-339`는 publication의 현장 인물에게 working을 준다. 기관 설명이 확인하는 시주와 공방에서의 물리적 출현·직접 인쇄는 다른 주장이다. [한국학중앙연구원 직지 항목](https://encykorea.aks.ac.kr/Article/E0022266).
4. **판각 집단의 모델 전달 경로가 끊긴다.** 원자료의 판각 인원은 Polity 집단이다. Person만 받는 현장 인물 경로에 들어가지 못하며 publication 분기는 익명 일꾼도 추가하지 않는다. 자세한 근거는 3절에 적었다.
5. **목록 부재와 화면 부재를 구분해야 한다.** 가마 분기는 catalog 밖에서도 원통과 그릇 geometry를 직접 만든다(`chronicle-event-scenes.js:164-173`). 반대로 catalog에 있는 모형이 해당 고려 scene에서 쓰인다고 볼 수는 없다. runtime의 `riverObjects=[]` 역시 이름으로 찾은 결과만으로 이름 없는 모든 물 geometry의 부재를 증명하지 않는다.

직업·성별을 고정 결합하지 않는다. 단순한 사람과 생활 부품을 쓰더라도 권력자·군사·승려뿐 아니라 노동·보관·운송·먹고 돌보는 관계를 읽을 수 있어야 한다. 해안과 산지에 같은 세트를 돌려 쓰는 방식은 이 표의 목적을 달성하지 못한다.

## 6. 우선순위와 실제 수용 장면

**먼저 고칠 것:** 사건 때문에 기존 수도·마을이 숨거나 줄어드는 구조, 역할·집단에서 실제 모델로 가는 연결, 건립과 시설 사용 기간의 혼용이다. 확인된 작은 오류를 고치면서 강도·인쇄·생활 공존 장면을 먼저 완성하고, 그 배치 방식을 수도·북방·해안·제주로 넓혀 검증한다. 전각 수나 새 archetype 수는 이 순서를 대신하지 않는다.

| 실제 수용 장면 | 관찰할 변화 | 통과 판단 |
|---|---|---|
| 강도 같은 카메라 1236→1237→1240→1249, 별도로 1251·1255 | 판각이 시작·진행·끝나도 행정·주거·시장 공간이 유지되고 시설은 해당 단계에 생김 | 도시가 압축되거나 작업이 사라지는 것으로 충돌을 해결하지 않음. 판각 집단이 익명 작업자로 전달됨. 1251의 국자감과 대장경 완성 사건을 같은 시설로 취급하지 않음. |
| 개경 1100→1101, 1231→1232→1233, 1269→1270→1271, 1391→1392 | 주민 생활·시설의 정체성과 수도·왕조 표지의 역할 변화를 함께 확인 | 관련 사건이 없다는 이유로 도시가 사라지지 않고 연도 하나로 전국 건축을 새로 만들지 않음. 확인된 파괴·복구는 무시하지 않음. |
| 벽란도–서남해 생산지–개경의 여러 관찰 지점, 자료가 겹치는 기간 | 포장·선적·운송·보관·소비와 항구 주변 일상 | 배 한 척이나 화물 소품만 떠 있는 것이 아니라 일이 이어짐. 설명용 연결선과 확정 항로를 혼동하지 않음. |
| 청주 1376→1377→1378, 관련 인물 선택 | 사찰 생활과 간행 활동, 묘덕의 후원 관계, 별도 장소의 후속 판본 | 제목·자료·동작이 서로 같은 사실을 말함. 사찰을 하루짜리 시설로 만들거나 시주자를 직접 인쇄공으로 꾸미지 않음. |
| 서경 생활 장면과 화주 1355→1356→1357을 각각 검사 | 전투·행정 변화와 지역의 거주·생업 | 평양 사진으로 화주의 성공을 대신하지 않음. 빈 중앙점 하나가 아니라 실제 배치된 생활권과 접근 경로를 이동해 봄. |
| 현행 제주 1270→1271→1273→1274→1276, 같은 연도 선택 전후도 별도 | 토성·군사·보급·주민·농경·해안 생활·말 사육 변화 | 사건 때문에 섬 전체의 가정·밭·길이 지워지지 않음. 선택/해제와 연도 변경의 효과를 따로 기록. 산·해안·성·주거의 상대 크기가 공존 가능함. |
| 각 장소의 멀리 보기→근처 보기→다시 멀리 보기 | 집과 시설의 형태·정체성, 전체와 상세의 연결 | 근경의 의미를 얻되 같은 집이 전혀 다른 집으로 바뀌지 않음. 가까운 상세를 제한하는 성능 구조를 유지함. |

검사에서는 같은 코드·해상도·품질·카메라·필터를 남긴다. 자료의 이름을 가리고 보는 검사는 공정 구별을 돕는 보조 검사이며, 역사적 맥락의 설명 자체를 없애라는 요구가 아니다. 간단한 geometry와 익명 배경은 허용한다. 반복되는 사용자 탐색에서 멈춤·화면 붕괴가 없는지 확인하고 필요한 성능 수치는 동일 환경의 기준 실행과 비교한다.

**확인됨:** 현행 대표 캡처 12장, 독립 코드 경로, 묘덕 역할 재현, 고려·조선 부품 동일성, compact 배치 목록, 이전 제주 감사의 두 셀 제거 기록, 필요한 기관 본문. **미검증/NOT_RUN:** 현행 제주와 이전 감사의 SHA 일치, 현행 제주 개별 셀 점유 추적, 새로운 전체 지형·브라우저 실행, 사용 기간이 불명확한 개별 민가·가마·묘역의 확정 복원, 저사양 기기·장시간 성능. 국가유산포털 일부 직접 open은 실패했으며 항파두리 안내판은 같은 공식 URL의 검색 본문으로 대조했다. 이 한계를 구현 완료나 역사적 부재로 바꾸지 않는다.
