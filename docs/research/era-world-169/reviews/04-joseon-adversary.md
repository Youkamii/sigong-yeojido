3. **P1/P2 분리 — 생활과 지역·사람의 의미:** JO-01/07은 위 표의 지역·시기별 생활 관계로 구체화한다. 부산의 집단 참여·소속, 김만덕의 상업 역할, 작업·연령 차이는 확인된 사례부터 보강한다. 상시 돌봄·직물·어업·장례의 미확정 관행은 연구 후보로 남기되, 기존 생활권을 비워 둘 이유로 삼지 않는다.
4. **별도 지형·거리 검증:** JO-08의 길·건물 바닥 문제를 분리한다. 160/60 비교에 더해 실제 LOD 임계 전후를 관측하고 동일 집의 위치·주거형·주변 생활 관계가 유지되는지 본다. 절대 모형 개수나 임의 프레임 수치 대신 같은 장치·내용 조건의 측정과 사용 가능한 이동 경험으로 판정한다.

현재 확인된 범위는 실제 이미지 12장, 동일 카메라 대조, 지정 코드·선택 데이터, 기관 원문 대조, 실제 composer의 제한된 평지 조립이다. 공개 새 캡처·현재 제주 셀별 추적·한성 최소 거리 결정 사건 추적·시설 경계 연도·북부 실제 근경·LOD 경계 통과·지속 성능 측정은 **`NOT_RUN`**이다. 이 한계를 유지해도 도시 크기·생활권 존속·행위 해석의 수정 필요성은 충분히 확인됐다.
