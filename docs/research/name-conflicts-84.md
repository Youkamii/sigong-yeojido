# 여러 이름과 국호의 충돌 집계 수정 (#84)

실제 9,416 Claim에서 신라의 여러 이름과 궁예의 904년 摩震·911년 泰封이 각각
단일 값 충돌로 집계됐다. 신라 Claim의 note는 이미 `hasName`을 다중 값으로 설명했지만
공용 규칙에서 빠져 있었다.

`hasName`·`hasStateName`을 검증기의 다중 값 목록에 넣었다. TTL 빌더와 뷰어 API가
이 목록을 함께 사용하므로 별도의 화면 규칙은 추가하지 않았다. 원 주장·이름·기간·인용은 유지한다.
이름이 같은 두 엔티티를 합치거나 표기의 동일성을 확정하는 변경도 아니다.

기존 검증기 테스트에 두 술어의 literal 객체를 적용했다. 네 테스트가 통과했고,
판독 문자처럼 한 값에 대한 서로 다른 읽기는 계속 집계되는 것을 함께 확인했다.
전체 데이터·운영 검사는 최종 수용 기록에 이어 기록한다.
