# 처음 불러오는 동안 누른 사료 선택 보존 (#82)

사료를 불러오기 전에 `모든 사료 켜기`를 누르면, 늦게 도착한 초기 설정이 사용자의 선택을
기본 렌즈 8개로 덮어썼다. 운영의 [실제 요청 기록](initial-source-selection-82-before.json)에서는
사료 응답이 4.261초 걸렸고 이후 광개토왕·918년 기록 조회가 기본 렌즈로 제한됐다.

초기 자료를 기다리는 동안 누른 전체 선택·해제의 마지막 값을 보관하고, 자료 도착 시 적용한다.
선택하지 않은 경우에는 기존 기본 렌즈를 적용한다. 선택이 확정되면 해당 연도의 기록 수도 갱신한다.

[실제 브라우저 검사](initial-source-selection-82-local.json)는 원 API 응답을 잠시 보류한 상태에서
전체 선택·해제·반복 선택을 누른 뒤 같은 응답을 전달했다. 기본값 8개, 전체 1,072개,
해제 0개, 마지막 선택 1,072개가 모두 유지됐다. 414년 기록 수 0/19도 선택과 일치했다.
인공 사료로 바꾸거나 기존 뷰어 검사의 기다림을 늘리지 않았다.

```sh
.venv-build/bin/python scripts/verify_initial_source_selection.py --out /tmp/initial-source-selection.json
```
