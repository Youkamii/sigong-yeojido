# 6세기 신라 인물 표본 (#51)

Claude Opus 5 / max 조사 완료본에서 주장 7개를 수록했다. 지증왕·법흥왕·진흥왕의 신라 소속 3개,
직접 적힌 재위 기간 3개, 삼맥종/심맥부의 인물 동일성 1개다. Source 3개, 짧은 인용 chunk 4개다.
실제 기관 HTML의 인용 대조는 `silla-sixth-quotes-51.json`의 4/4이며 페이지 해시를 남겼다.

6세기 조건 검색은 501~600년을 쓴다. 조사 초안의 500~599년 겹침 파생 주장 3개는 저장하지 않았다.
재위 기간은 해당 시기 활동 근거이며 생몰년 전체와 다르다. 세 명은 수록 표본이고 당시 모든 인물 목록이 아니다.
현대 해설을 삼국사기 원문으로 바꾸지 않았으며, 다른 사료의 같은 이름을 자동으로 합치지 않는다.
별도 렌즈 `silla-sixth-century`로 세 Source를 선택할 수 있다. 사람의 역사 해석 검토는 미완료다.

재현: `python scripts/import_silla_people.py --research <완료된 조사 폴더> --checks docs/research/silla-sixth-quotes-51.json --out docs/research/silla-sixth-century-51.json`
실제 초안·모델 실행 기록은 `data/research/silla-sixth-century-51/`에 있다.
