## 규칙과 집계

범주 접두어 7건은 `설화 ·`를 제거하고 다음 세그먼트를 본제목으로 삼았다. 뒤의 책 편찬·간행 시기는 제거했다. “3자 이하”는 범주 접두어 문맥에서 적용했다. 지시서가 본제목 보존 예시로 명시한 김주열·전태일·의상·진대법 같은 짧은 고유명사에는 적용하지 않았다.

장소는 place.label 포함 관계와 기존 지명 판정, 행정 지명·장소 접미를 가진 명사구를 대조했다. `창원의 기계 공단`, `제천의 창의` 등은 장소 부제로 분류했다. `사이공에 닿은 수송선`, `추풍령을 넘는 길`, `졸본에 고구려를 세우다` 등은 장소 이름이 있어도 이야기로 남겼다. 판단이 갈리는 `마산 3·15 항의 시위와 김주열`도 남겼다. 장소명 `앞바다`는 서술어로 보지 않았다.

### 제목에 의존하는 파생 값

제목 기반 추정 때문에 달라진 기존 side·supersededBy 5건은 수정 4와 같은 방식으로 이전 값을 보존했다. 저장 전 빌드는 `fix5-build-metadata.before-preserve.json`, 보존 내역은 `fix5-scenes-direct.json`에 있다. 제목·역할 문자열을 가리면 전후 장면 JSON의 바이트가 같다.

| scene-jikji-1377 / supersededBy | None | scene-gl4-jikji |
| scene-harbin-1909 / supersededBy | None | scene-hs-mt4-harbin-assassination |
| scene-bj-garimseong-501 / participantGroups.0.side | a | b |
| scene-bj-wangheungsa-600 / participantGroups.0.side | a | b |
| scene-cfc-wangheungsa-600 / participantGroups.0.side | a | b |

**정정(#199 round 2).** `side` 보존 3건은 되살리지 않았다. `scene_vocabulary.normalize_group` 은 장면의 제목·요약·역할에서 대표 정치체를 찾아 편을 정하는데, 현재 코드로 계산하면 세 장면 모두 빌드값 `a` 가 맞다(보존값 `b` 는 옛 어휘표 시절의 값이다). 이번 재빌드로 `scene-bm-gwanbang-386`, `scene-us2-paegang-wall-826` 까지 5건이 `b`→`a` 로 돌아왔다. 옛 값을 계속 보존하면 재빌드할 때마다 같은 수작업이 필요하므로 빌드값을 그대로 둔다.

`docs/research/scene-supersede-186.json`은 지시대로 빌드가 만든 결과를 그대로 두었다. 따라서 보존한 장면의 중복 연결과 빌드 보고서가 다를 수 있다. 이 파일도 리더가 커밋에 포함할 대상이다. 빌드만 재실행하면 위 메타데이터 차이가 다시 생길 수 있으므로 보존 절차와 전수 대조를 함께 실행해야 한다.
