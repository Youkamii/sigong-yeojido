# 국사편찬위원회 문의 초안 — 미발송 (#36)

대상: 공공데이터포털 국편 원문 XML 담당자. 발송 여부는 사용자 결정이다.

한국사 원문 벌크 XML을 출처별로 보존하는 작업 중 다음 규격을 확인하고자 합니다.
자료는 삼국사기(15053635), 삼국유사(15053634), 고려사(15053637), 고순종실록(15053646)입니다.

1. `dateOccured/@date`의 공식 입력 지침과 버전을 알려 주실 수 있습니까? 공공데이터포털의 고려사절요(15115521)·한국독립운동사자료(15115618) 원 ZIP에 포함된 history.dtd ver 1.4(2020-07-30)에서도 속성값은 CDATA로만 선언되어 있고 L0/L1/LO/99의 정의를 찾지 못했습니다.
2. 접미사 `L`과 마지막 숫자 0·1의 뜻 및 허용되는 다른 값은 무엇입니까? 고순종실록의 1896년 이후에도 L0가 있습니다.
3. 월·일의 `99`는 미상 표시입니까? 연도에도 미상 코드가 있습니까? `-0057`은 기원전 57년을 뜻합니까?
4. 월·일은 원문의 값을 유지합니까, 환산한 값입니까? 날짜 라벨의 괄호 월은 어떤 경우에 붙습니까?
5. 고려사 `kr_024_0070_0081_0020`의 `1257-08-20LO`는 마지막 글자가 대문자 O입니다. 별도 코드인지 입력 오류인지 확인 부탁드립니다.
6. 삼국유사 `sy_001_0020_0030_0020`의 `0111-99-99L0`는 본문의 元封二年과 어떻게 대응합니까?
7. 삼국사기 `sg_013_0020_0010`, `sg_037_0030_0120`의 벌크 본문에는 淲가 있습니다. 과거 웹·벌크 대조에서 제기된 淲/㴲 차이의 교감 근거와 현재 채택 글자를 확인할 수 있습니까? 현재 웹 본문은 재수집하지 않았습니다.
8. 파일명에 20221103이 붙은 벌크의 원문 기준 시점과 웹 교감 반영·재배포 주기를 알려 주실 수 있습니까?

관련 전수 집계와 해당 ID의 원표기는 `date-character-census.json`, `modern-date-census.json`으로 제공할 수 있습니다.
이 초안은 날짜·글자 문의만 다룬다. 웹 본문 재이용 허락 문의(인수인계 §7.10)는 별도로 결정한다.
