# 연도에 맞춘 이름 없는 생활 배경

실제 Claude Opus5 Max 조사에서 국가기록원·국립대구박물관 6개 페이지의 원문·해시·짧은 인용을 확인했다. 원 조사와 채택 범위는 `data/research/period-scenery-130`에 있다.

생활 배경은 이른 정주·초기 농경·전통 농촌·근현대 초기·지붕 전환·농기계 사용의 넓은 화면 구간으로 나뉜다. 집과 생활 인물·도구가 달라지고, 현대 배경에는 야생 호랑이가 계속 남지 않는다. 지붕 전환기에는 옛집과 새집이 섞인다.

구간의 시작 연도, 집 비율, 복식·농기계 외형은 표시 설정이다. 모든 지역이 같은 해에 바뀌었다는 주장이 아니다. 이번 지붕 개량·농기계 자료는 남한 자료이므로 북위37.7도 남쪽의 배경에만 반영했다. 이 위도는 자료 적용을 보수적으로 제한한 화면 범위이며 국경이 아니다. 북부의 시대별 농촌 외형, 삼국·고려·조선의 복식과 가옥 차이, 실제 마을 평면은 추가 자료가 필요하다.

같은 구간에서 연도를 바꾸면 마을 조형을 재사용한다. 구간이 바뀔 때는 작은 단위로 작업을 나누며, 이미 지난 선택의 작업은 중단하고 최종 연도만 완성한다. 교체한 조형과 원경용 조형의 GPU 자원을 반환한다. 논밭·길의 바탕과 숲은 재사용한다.

`scripts/verify_period_scenery.py`의 실제 API 연결 검사13개가 로컬에서 통과했다. 연도별 모형, 같은 구간 재사용, 이전 geometry 반환, 빠른 방향 전환, 표시 선택, 사건과의 충돌을 검사했다. [로컬 결과](period-scenery-local-130.json).
