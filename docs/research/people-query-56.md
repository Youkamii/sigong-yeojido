# 인물·기간·소속 조건 검색 (#56, Q3)

`/api/people?polity=polity-silla&from=501&to=600&sources=...&origin=all`은 실제 Fuseki의
Person, 소속 Claim, 활동 기간 Claim을 조회한다. 같은 선택 사료가 두 조건의 근거를 갖춰야 한다.
`isKingOf/memberOf/affiliatedWith`와 `reignedIn/activeIn/appearsIn/livedIn`을 사용한다.
숫자로 확인된 양 끝(또는 단일 year)이 질의 구간과 겹치는 인물을 돌려준다.
연도를 모르는 기록을 생존 구간으로 추정하지 않고, 생몰년 전체를 재위 기간으로 대체하지 않는다.

왼쪽 ‘기간·나라로 인물 찾기’에서 나라·시작·끝을 입력한다. ‘6세기 신라 인물’ 렌즈는
현재 수록한 기관 해설 세 항목을 켠다. 결과 → 주장 → 인용한 원문으로 이어진다.
기존 엔티티 근거 패널에도 각 Claim의 직접 원문 버튼을 달았다.

실제 자료 검사 `scripts/verify_people.py` / `people-56-local.json`:
- 501~600년·신라: 지증왕, 법흥왕, 진흥왕 3명과 직접 원문 일치.
- 한 명씩 페이지를 넘겨 중복·누락 없음. 빈 시대·다른 나라·전체 사료 해제·사람 작성 필터는 빈 결과.
- 0년은 입력 오류. 1440px·480px 화면에서 조건 검색과 근거 열기, AI 제외 갱신 통과.

이는 **수록 데이터의 실제 질의 검사**다. 당시 신라 인물을 전부 수집했다는 뜻이 아니다.
활동 연대가 별도 환산 Claim에만 있는 경우를 이 API가 자동 합성하지 않는다. 시간축의 환산 조회와 구별한다.
한 페이지는 인물 최대 100명, 근거 최대 2,000쌍이며 더 있는지를 응답에 표시한다.
