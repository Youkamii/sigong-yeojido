# 통사 뼈대의 실제 범위와 연대 분포 (#51)

현재 뼈대는 대표 사건·인물·지명·소속·연대를 원문과 연결하는 범위다.
모든 인물의 생몰·계보, 모든 사건, 사료 전문에서 추출할 수 있는 모든 주장을 수집한 것은 아니다.
2026-09-07 운영 RDF에서 Claim 9,418개를 확인했다. 행정·국가 경계 레코드 연결은 9,028개,
현재 옛길 코스 기록은 1개, 그 밖의 관계는 389개다. 주장이 있는 Source는 85개다.
경계와 현재 코스의 수를 역사 해석의 두께로 세지 않는다.

#51의 원래 완료 기준 네 가지를 대조해 이슈 범위의 작업을 완료로 정리했다.
비전의 현재 범위는 전 시대를 얕게 연결하는 뼈대이며, 시대별 심화와 전면 수집 규모 확대는 다음 범위다.
앞서 시대별 두께가 고르지 않다는 이유로 #51을 부분으로 표시한 것은 이 두 범위를 섞은 판정이었다.

| 원래 완료 기준 | 실제 근거 |
|---|---|
| 대표 사건·인물·지명·소속·연대의 수집 범위 명시 | 아래 8개 구간의 대표 범위와 미수록 자료 |
| Opus 5 Max 조사·Codex 통합 | 연결된 연구 실행 기록·원 HTML 대조 기록. 세션 한도 오류도 그대로 보존 |
| 원문·직접 인용·Source·AI 작성 표기·digest | [운영 Q4](core-questions-goal.json)의 9,418개 Claim·9,242개 인용 chunk 전수 대조와 기존 digest 검사 |
| 실제 시대·사료별 분포와 미수록 범위 공개 | [현재 RDF 집계](claim-periods-goal.json)와 아래 표. 85개 Source에 Claim이 있고 990개에는 없음 |

전체 역사 자료의 수집을 완료했다는 뜻은 아니다. 더 깊은 인물·사건 연결과 원문 공백은
[통사 수집 목록](corpus-gaps-52.md)에 남겨 두고, 위치 근거·역로·공식 확인도 각 이슈에서 계속 추적한다.

이번에는 [기관 해설의 42개 연결](era-spine-51.md), [평양 장소 견해 3개](pyongyang-direct-61.md),
[사건 장소·날짜·좌표 15개](khs-events-81.md)를 보강했다.
각 주장에는 실제 chunk·직접 인용·Source·AI 작성 표기·digest가 있다.
조사는 Claude Opus 5 / Max, 인용 대조와 통합은 Codex가 담당했다.
세션 한도로 중단된 조사는 저장된 초안만 사용하고 원 호출의 오류 상태를 유지했다.

| 구간 | 현재 대표 범위 | 남은 자료 |
|---|---|---|
| 고조선·부여·삼한 | 단군 표기, 고대 사서 발췌, 부여의 존속 서술 | 위만조선·옥저·동예·삼한 인물의 촘촘한 연결 |
| 고구려·백제·신라·가야 | 광개토왕비, 건국 연대 대조, 신라 6세기 왕, 대가야 멸망과 참여자 | 후대 왕 계보, 생몰, 사건·고분군의 직접 연결 |
| 통일신라·발해·후삼국 | 문무왕의 서술, 발해 건국자, 견훤·궁예·마진·태봉 | 발해 왕 계보, 936년 통일 사건의 추가 인용 |

| 북한 | 자체 작성 보고서, 헌법 전사본, 기관 해설의 별도 주장 | 판본 확정, 인물 승계·생몰, 자체 학술 연구 확대 |

이 표의 구간은 수집 범위다. [RDF에서 센 실제 연대 분포](claim-periods-goal.json)는 다음과 같다.
정규화 연도 또는 닫힌 연도 범위를 목적어에 가진 Claim은 48개, 범위가 미상인 시간 Claim은 40개다.
나머지 9,330개는 인물·장소·명칭 등 다른 목적어이며 사료의 편찬 시점으로 날짜를 대신 채우지 않는다.

| 숫자 연도 구간 | 겹치는 Claim |
|---|---:|
| 기원전 | 2 |
| 1~699 | 20 |
| 700~934 | 5 |
| 935~1391 | 3 |
| 1392~1875 | 4 |
| 1876~1944 | 5 |
| 1945 이후 | 11 |

여러 구간에 걸친 범위는 각 행에 중복 집계하므로 표의 합계가 고유 Claim 수는 아니다.
환산 연도가 없는 원표기와 자료가 스스로 적은 숫자 연도의 차이는 각 시간 객체에 남긴다.
보고서에는 집계에 쓴 Claim ID·출처·숫자 범위와 전체 술어·Source별 수가 있어 재확인할 수 있다.

```sh
python scripts/report_claim_periods.py --out /tmp/claim-periods.json
python scripts/report_claim_coverage.py --out /tmp/claim-coverage.json
```
