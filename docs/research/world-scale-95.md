# 넓은 한반도 역사 세계 (#95)

사용자는 #94의 작은 지도를 거부했다. 한반도 전체 역사의 사람과 사건을 담을 공간이 필요하며,
전체를 한 화면에 맞추려고 축소한 모형을 원하는 것이 아니다.

## 바뀐 동작

- 한반도 투영의 가로·세로를 각각 8배로 넓혔다. 면적 배율은 64이며 인물과 건물 크기는 유지한다.
  현재 표시 공간은 약 762 × 1,482 월드 단위다. 고도는 같이 8배로 늘리지 않는다.
- 첫 화면은 실제 사건 장소를 우선한 가까운 지역 장면으로 진입한다. 현재 1593년은 행주 주변이다.
- 드래그 이동, 휠·버튼 확대/축소, 인물·사건 선택 이동, 한반도 전체 보기와 지역 복귀를 연결했다.
  연도를 바꿨을 때 새 기록이 현재 시야에 하나도 없으면 해당 시대 장면으로 이동한다.
- 좌표 투영과 역변환, 지형 높이, 카메라 이동 범위와 원거리 표시·안개를 같은 지도 크기에 맞췄다.
  가까운 장면의 그림자 계산 영역도 시야에 맞춘다.
- 약 12,000그루의 원본 Fantology 나무를 공간별로 묶어 화면 밖 묶음을 잘라 그린다.
  인물·건물도 지역별로 생성하고 각 묶음의 160개 생성 한도가 전체 자료를 잘라내지 않게 했다.
- 모바일 이동 도구는 높이를 줄여 조형이 보이는 공간을 남겼다.

기능 커밋 `1df1d42b`, 모바일 `24651c9f`, 그림자 범위 `90501010`.
원본 엔진·재질·스타일·모형 생성기는 수정하지 않았다. 새 역사 조사를 포함한 작업이 아니다.

## 실제 검사

- `node scripts/test_chronicle.mjs`, `node scripts/test_chronicle_assets.mjs`: 통과.
- [개발 화면 검사 21개](world-local-95.json): 투영·배치·이동·연도·실제 모델 클릭·근거·모바일·161개 생성 통과.
- [최종 공개 주소 검사 22개](world-production-95.json): Windows headless Chromium, 기본 화질 선택 결과 medium.
  동일 기능과 사료 전체 해제까지 통과. 161개는 생성 한도 검사에만 사용한 별도 테스트 조형이며 수집한 역사 인물 수가 아니다.
- JavaScript·WebGL 오류 0. 일반 Chromium이 자동 요청하는 `/favicon.ico`의 404는 별도 `browserResourceErrors`에 남겼다.
  기존 사이트의 탭 아이콘 누락이며 역사 모델의 로딩 오류로 집계하지 않는다.
- [c2 소프트웨어 렌더러의 초기 기본화질 캡처](world-software-capture-95.json)는 90초 시간 초과로 실패했다.
  이를 통과로 바꾸지 않았다. 최종 화면·동작 검증은 Windows의 headless Chromium에서 실제 공개 주소로 수행했다.

## 남은 범위

지도 공간 확대는 한국사 전체 자료 수록의 완료가 아니다. [#96 자료 공백](history-coverage-96.md)이 남아 있다.
실제 역사 인물의 위치가 확인되지 않은 모형은 계속 상징 배치로 표시한다.
이 변경의 동작 검사 통과를 사용자 디자인 수용으로 표현하지 않는다.
