# 출처가 있는 이동 조건의 일관성 검사 (#54)

`physicallyPresentAt`과 `minimumTravelHours`의 입력 조건을 정하고 기존 검증기·빌드에 연결했다.
구체적인 필드는 [스키마 §11.1](../02-schema.md#111-실행하는-역사-규칙과-남은-조건-54)에 있다.
두 출현과 이동시간 하한 모두 기존 인용 검사를 받으며, 조건 전체를 digest·RDF·그래프 응답에 보존한다.

같은 인물·같은 사료의 두 출현에 닫힌 시각 범위와 위치 오차가 있어야 한다.
오차 영역이 겹치지 않고 두 시각 범위의 순서가 분명할 때만 비교한다.
이른 출현의 가장 이른 시각부터 늦은 출현의 가장 늦은 시각까지도 이동시간 하한보다 짧으면 오류다.
입력의 이동시간 하한은 위치 오차까지 고려한 근거여야 한다. 기본 속도나 시대별 추정 속도는 넣지 않았다.

Claude Opus 5 / Max 조사에서는 한국사 원문에서 이 조건을 모두 갖춘 실제 사례를 확보하지 못했다.
파발의 참 간격은 이동속도가 아니고, 유럽 중세 이동속도 평균도 한국사에 쓸 상한이 아니다.
그래서 수록 자료에 수치를 만들어 붙이지 않았다. 원 조사 호출의 식별자는
`820a0226-50e5-4d03-8b92-900d68a66615`이며 숨겨 실행한 정상 완료 호출이다.

검증 결과:

- 새 인공 사례 7개 통과: 가용시간 최대값, 경계값, UTC 오프셋, 미상·겹침·사료/인물 분리,
  잘못된 참조·수치·시각, 실제 검증기의 인용 실패, TTL의 조건 보존과 그래프 객체 복원.
- 전체 Python 102개 통과. 기존 충돌 검사 테스트가 새 술어에 잘못된 entity 객체를 넣던 부분은
  지리 술어의 실제 객체를 사용하는 새 검사로 옮겼다. 다중 값 충돌 제외도 새 검사에서 확인했다.
- [실제 수록 자료 적용 현황](geography-rules-54-current.json): Claim 9,265개 중 조건을 갖춘 입력 0개,
  실제 비교 0개. 이 수치를 실제 역사 사례의 검증 성공으로 세지 않는다.

이 규칙은 입력된 주장과 이동 조건 사이의 앞뒤가 맞는지 확인한다.
특정 인물의 역사적 동일성이나 사료의 신빙성을 자동 확정하지 않는다.
