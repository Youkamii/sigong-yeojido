# 시대별 뼈대의 빈 연결 보강 (#51)

기관 해설·법령 표제 15개에서 인용 28개, 주장 42개와 새 엔티티 29개를 추가했다.
부여·가야·후삼국·조선·개항·대한제국·임시정부·현대 헌법·북한의 빈 구간을 보강한다.
고려 구간은 기존 원문 주장을 유지했다. 화면에서 **시대별 뼈대 · 기관 해설** 렌즈로 선택할 수 있다.

Claude Opus 5 / Max 호출은 세션 한도로 오류 종료했다. 그 전에 저장한 초안을 Codex가 원 HTML과
직접 대조한 뒤 사용했다. [실행 기록](../../data/research/era-spine-51/run.json)의 오류 상태를 유지한다.
초안에 빠졌던 구절, 곧은 인용부호, 이사부의 한자 차이를 수정했다. 대한제국 즉위식 날짜는
원문의 10월 11일 국호 결정과 다음날 12일 즉위식을 함께 인용했다. 연호는 인용 그대로 `광무`로 쓴다.

시작 연도가 없는 부여·금관가야의 범위, 가야의 세기 표기, 북한 수립 문장의 연도 공란을 보존한다.
음력을 양력으로 바꾸지 않았다. 현대 해설, 법령의 공포·시행 메타데이터, 당시 사료 원문을 구분한다.
자료에서 인용하지 않은 대성동 고분군과 전권대신 엔티티는 추가하지 않았다.

원문은 각 페이지당 25단어 이내로 인용했다. 전체 자료의 자유 재배포를 뜻하지 않는다.
[출처·해시·수정 기록·시대별 남은 자료](era-spine-51.json)에 근거를 남겼다.
현대 해설의 인물 표기를 기존 실록 인물에 자동 병합하지 않는다.

같은 입력으로 재실행하여 내용 일치를 확인했다. 전체 검증에서 주장 9,307개,
인용·참조·digest 실패 0개이며 TTL 241,606 트리플이 생성됐다.
실제 운영 그래프·필터 검증은 다음 배포 기록에 남긴다. 모든 시대의 인물·사건 전수 수집을 마친 것은 아니다.

```sh
python scripts/import_era_spine.py --research /path/to/era-spine-gaps-51 --cache /path/to/spine-checked --out docs/research/era-spine-51.json
python services/validate.py --write-digests
python services/build_ttl.py
```
