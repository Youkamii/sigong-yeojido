기존 데이터에는 이미 유효기간이 있었다. 이번 변경은 그 기간 안에서도 매년 다시 만들던 역사 장면과 인물의 3D 객체를 재사용한다. 현재 연도와 설명은 갱신하며, 등장·퇴장·외형·배치가 달라지면 해당 객체를 교체한다. 매 프레임의 화면 렌더링 자체를 없앤다는 뜻은 아니다.

[실제 공개 주소 검사](period-world-158/public-time-territory.json)는 로컬 파일 대체 없이 실행했다. 4px 이동에서 1500→1501년, 2.7초 유지에서 가속, 놓은 뒤 연도 정지, 600년 고구려·백제·신라, 1500년 조선 표시가 모두 통과했다. 브라우저 오류 0개다.

[실제 API 연도 전환 검사](period-world-158/live-api-object-reuse.json)는 통합 프런트와 운영 API를 연결했다. 1500→1501년의 도시 3개, 1592→1593년 한성, 1594→1595년 이순신 조형에서 객체 동일성을 확인했다. 14개 비교에서 같은 시각 입력인데 객체가 교체되는 경우는 없었다. 새 사건 추가와 기간 종료 사건 제거도 확인했다.

## 시대별 조형과 도시 통합 검사

인물·마을·도시 조형을 합친 [배포 전 UI 검사](period-world-158/integrated-ui-before-city-data.json)는 33/33 통과했다. 이 기록은 지방 도시 데이터 추가 전이며 공개 배포 확인을 대신하지 않는다.

카메라·LOD가 추가된 뒤 기존 재사용 검사에 카메라가 없는 문제가 드러났다. 테스트를 실제 카탈로그 로더와 카메라를 쓰도록 고치고 다시 통과했다. 시대별 인물 선택에서 빠진 익명 마을 주민과 문인도 통합 검토 대상으로 삼았다.

조형의 시대 구분과 골목 배치는 화면용 표현이다. 개별 인물의 정확한 복식, 특정 도시의 실제 가옥 수나 거리 배치를 복원한 것으로 세지 않는다. 유효기간과 이름·수도 역할의 근거는 별도로 보존한다.

모든 브라우저 검사는 headless Chrome이다. 모바일은 화면 크기와 터치를 모사했으며 물리적인 기기 검사는 NOT_RUN이다. AI 대화 전송만 모의 응답으로 검사했고 실제 모델 응답은 NOT_RUN이다. GitHub Actions workflow는 0개다.

짧은 약 1.4초 성능 표본은 검사 JSON에 보관했다. 최종 도시 데이터와 무관한 중간 측정이며 서로 다른 장면의 FPS를 직접 개선 비율로 비교하지 않는다. 한반도 지형·해안선·강 파일은 이번 변경 범위에 포함하지 않는다.
