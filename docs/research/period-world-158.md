[인물 근거와 한계](figures-161.md) · [마을 조형과 검사](villages-162.md).

도시는 주거 구역·시장·관아·외곽 취락을 여러 작은 조형으로 구성하고 멀리서는 간략히 표시한다. 골목과 건물 수는 상징적인 배치다. 한성의 자세한 장면은 141개 조형으로 구성했다. 마을은 최대 88곳이고 같은 시대 안에서는 재생성하지 않는다. 남쪽의 지붕 개량 비율을 북쪽에 적용하지 않는다.

새 지방 도시는 원주·전주·강릉·안동·진주·청주·충주·남경·목포·인천·제주·해주·함흥이다. 확인된 이름·지위가 이어지는 구간만 표시하며 도시의 전체 존속 기간이라고 주장하지 않는다. [기관 원문 대조 기록](../../data/research/regional-cities-163/review.json)과 [승인 입력](../../data/research/regional-cities-163/approved.json)에 원문 URL·파일 해시·짧은 발췌·좌표의 범위를 남겼다. 남경·원주·충주 등은 지역 범위의 참고 좌표이며 실제 관아나 개별 건물의 정확한 자리로 해석하지 않는다.

한성은 1394년 한양부, 1395년 한성부 개칭을 구분했다. 1399–1404년은 수도 역할이 없는 기록 사이 도시 배경으로 표시하고, 그해 발생한 사건 목록에서 제외한다. 1405년 수도 역할을 다시 표시한다. 기존 Claim을 지우지 않고 새 기관 근거를 더했으며, 현재 배경의 장소를 눌러도 과거 수도 연도로 이동하지 않는다.

추가분은 Source 16개·원문 발췌 26개·Claim 42개다. [전체 데이터 검증·RDF 빌드](period-world-158/data-build.json)는 Source 1,857개·Claim 12,811개·316,201트리플, 경고 0·실패 0으로 통과했고 Turtle 구문 검사도 통과했다.

[실제 지형의 도시 배치 검사](period-world-158/city-terrain-after-fix.json)에서 새 도시 13곳 모두 중심 조형이 남고 생성된 모든 모델이 육지에 있었다. 앞선 검사에서 강릉·제주의 관아 배치가 바다로 나가 도시가 빠졌던 [실패 기록](period-world-158/city-terrain-before-fix.json)도 보관했다. 근거 좌표와 지형을 유지하고 육지인 기준점에 중심 조형을 놓도록 고쳤다. 목포는 참고 좌표 중심이 표현 지형의 물 위에 있지만 실제 조형은 주변 육지에 놓인다. 이는 지역 범위의 상징 배치이며 새 정확한 위치 근거가 아니다.

인물·마을·도시 조형을 합친 [배포 전 UI 검사](period-world-158/integrated-ui-before-city-data.json)는 33/33 통과했다. 이 기록은 지방 도시 데이터 추가 전이며 공개 배포 확인을 대신하지 않는다.

카메라·LOD가 추가된 뒤 기존 재사용 검사에 카메라가 없는 문제가 드러났다. 테스트를 실제 카탈로그 로더와 카메라를 쓰도록 고치고 다시 통과했다. 시대별 인물 선택에서 빠진 익명 마을 주민과 문인도 통합 검토 대상으로 삼았다.

조형의 시대 구분과 골목 배치는 화면용 표현이다. 개별 인물의 정확한 복식, 특정 도시의 실제 가옥 수나 거리 배치를 복원한 것으로 세지 않는다. 유효기간과 이름·수도 역할의 근거는 별도로 보존한다.

모든 브라우저 검사는 headless Chrome이다. 모바일은 화면 크기와 터치를 모사했으며 물리적인 기기 검사는 NOT_RUN이다. AI 대화 전송만 모의 응답으로 검사했고 실제 모델 응답은 NOT_RUN이다. GitHub Actions workflow는 0개다.

짧은 약 1.4초 성능 표본은 검사 JSON에 보관했다. 최종 도시 데이터와 무관한 중간 측정이며 서로 다른 장면의 FPS를 직접 개선 비율로 비교하지 않는다. 한반도 지형·해안선·강 파일은 이번 변경 범위에 포함하지 않는다.
