# 국편 원문·번역문 이용 범위 문의 초안 — 미발송 (#12)

수신 대상은 국사편찬위원회 공공데이터/XML 제공 담당 부서다.
자료 식별 페이지는 [삼국사기 15053635](https://www.data.go.kr/data/15053635/fileData.do),
[고려사절요 15115521](https://www.data.go.kr/data/15115521/fileData.do),
[한국독립운동사자료 15115618](https://www.data.go.kr/data/15115618/fileData.do)다.
공개 담당 전화는 연구편찬정보화실 **02-500-8387**로 공식 HTML 세 건에서 확인했다.
서면 접수 주소와 발신자·회신 주소는 확정하지 않았으며 발송도 하지 않았다. [창구 확인 기록](nikh-contact-12.md)
기존 [날짜·글자 문의](nikh-inquiry-draft.md)와 별개의 이용 범위 문의다.

---

제목: 공개 배포 원문 XML의 문단 분할·공개 제공 및 번역문 제공 경로 문의

안녕하세요. 역사 원문과 그 원문을 인용한 주장을 함께 보여 주는 ‘시공여지도’ 프로젝트를 개발하고 있습니다.
공개 웹 뷰어와 GitHub 저장소에서 자료를 제공하려고 하며, 아래와 같이 처리합니다.

- 공공데이터포털에서 배포한 XML을 사용하고 원 제공기관·데이터셋·원 ID·출처 URL·이용조건을 기록합니다.
- 기사를 JSONL 문단으로 나누고 원문과 주석·서지·날짜 원표기를 보존합니다. 현대 번역문은 원문과 구별합니다.
- 원문 전체를 역사적 사실로 단정하지 않고, 인용에 기반한 별도 주장을 AI 초안으로 표시합니다.
- 데이터를 내려받아 볼 수 있는 공개 저장소와 웹 검색·근거 열람 화면을 제공합니다.

자료와 실제 처리 예시는 [저장소](https://github.com/Youkamii/sigong-yeojido),
[삼국사기 카드](https://github.com/Youkamii/sigong-yeojido/blob/main/data/sources/samguksagi.md),
[고려사절요 카드](https://github.com/Youkamii/sigong-yeojido/blob/main/data/sources/goryeosa-jeolyo.md)에 있습니다.

1. 공공데이터포털에 ‘제한 없음’ 또는 공공누리 제1유형으로 표시된 원문 XML은 위와 같은
   문단 분할·형식 변환·공개 저장소 재배포·웹 검색 제공에 사용할 수 있습니까?
   국편 웹사이트의 이용 안내와 별도로 배포본에 적용되는 조건이 있는지 확인 부탁드립니다.
2. 원문·교감주·원주·현대 해설·번역·서지·색인 중 권리 또는 이용조건이 다른 부분이 있다면
   구분 방법과 필요한 추가 허락을 알려 주실 수 있습니까?
3. 상업적 이용 여부에 따라 달라지는 조건, 반드시 보존해야 하는 출처 문구·변경 표시·링크가 있습니까?
   허용되는 이용 범위와 제한을 자료별로 기록하고자 합니다.
4. 삼국사기·삼국유사·고려사 등의 번역문을 이러한 공개 서비스에서 제공할 수 있는 별도 배포본이나
   신청 절차가 있습니까? 웹 본문과 번역문을 자동 수집할 허락이 있다고 전제하지 않습니다.

가능하다면 적용되는 공식 안내의 URL·버전과 회신의 인용·공개 가능 여부도 함께 알려 주시면 감사하겠습니다.

이 초안은 기관의 허락을 받은 문서가 아니다. 실제 제출은 HANDOVER §7.10의 사용자 결정 뒤 진행한다.
회신을 받기 전에는 이 문서로 기존 배포 조건이나 자료 카드의 라이선스를 바꾸지 않는다.
