# 현장 탐색·표시 선택·연도 입력 — #120·#121·#124

인물을 선택하면 해당 시기의 현장으로 들어가는 동작을 유지하고, 지도 안에 사건과 현장 인물을 함께 읽는 카드를 둔다.
사건이 하나뿐이어도 사건 버튼을 표시하고, 인물의 당시 역할을 함께 보여 준다. 연도 변경·사료 해제로 장면이 없어지면
이전 카드를 닫는다. 현장에 있었다는 근거가 없는 관련 인물은 이 현장 인물 카드에 넣지 않는다.

‘지도 표시’에서 지역명·산과 섬 이름·인물 이름·사건 이름을 따로 고른다. 이는 이름표를 고르는 설정이며 모형은 유지한다.
마을·밭·동물, 숲, 길은 별도의 풍경 설정으로 켜고 끈다. 선택은 연도 변경과 새로고침 후에도 보존한다.

연도는 테두리가 있는 입력칸에 직접 입력하고 ‘이동’ 또는 Enter로 확정한다. 기원전은 음수로 입력한다.
[실제 c2 자료를 연결한 로컬 브라우저 검사](map-controls-local-121.json)가 통과했다. 입력·BCE·선택 확대·사건과 인물 동시 표시,
이름표·풍경 토글, 연도 변경·새로고침·모바일을 실제 조작했다. 오류 없음.
