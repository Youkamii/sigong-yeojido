# 주 렌즈와 비교 사료 (#48)

기본값은 출처가 있는 현대 연구 발췌 8개 Source다. 한국민족문화대백과사전 집필 항목과 동북아역사재단 지도 항목이며, 지역 대표점을 위한 GeoNames가 포함된다.
현재 확보한 일부 위치 자료에 한정하며 전 시대 통설을 모두 수록한 렌즈로 부르지 않는다. 항목마다 출처·집필자·인용을 남긴다.

`data/lenses.json`에 기본값과 선택지를 기록했다. 주 렌즈를 바꾸면 그 사료들을 선택하고, 사용자가 추가로 켠 사료는 비교 대상으로 겹친다.
모든 개별 사료를 주 렌즈로 삼을 수도 있다. 좌표 연결에 필요한 Source는 사료를 켤 때 함께 선택한다. 모두 끄면 연결과 3D 클릭 대상도 사라진다.

지도와 3D는 같은 함수로 주 렌즈의 진하기 1, 비교 사료 0.32를 적용한다. 시간축에서도 비교 사료를 같은 진하기로 표시한다.
두 논문이 같은 GeoNames 레코드를 쓴다는 이유로 두 견해가 모두 주 렌즈가 되지는 않는다.

[브라우저 검증](lenses-48-browser.json)은 실제 수록한 국내성 집안 지점과 철령 지역 견해를 켜고, 근거·2D 진하기·3D 객체·전체 해제·3D 틀 밖 방향 기준점을 대조했다.
로컬 최신 뷰어를 c2의 숨김 브라우저로 검사한 결과다. 운영 반영 검증은 따로 기록한다.
전체 Python 84개, JavaScript 13개 검사도 통과했다.
