# 북한 헌법 전사 발췌 (#66)

Opus 조사에서 가져온 위키문헌 전사 두 문장을 현재 HTML과 대조했다. 국호를 적은 문장만 AI 초안 Claim으로 만들었다.
북한이 발행한 원본이나 확정된 판본으로 취급하지 않는다. 판본·조문 위치·수록 시기와 작성 연도는 미확정 상태로 남겼다.
통일법제 데이터베이스의 1972년 채택일을 이 전사본에 붙이지 않았으며, 해당 주장도 제외했다.

원문의 “리익”, “사회주의위업”을 유지했다. 사람의 검토 완료 기록은 없다.
별도 Opus 조사에서 북한이 작성하고 국제기구가 배포한 문서를 찾고 있으며 그 결과는 별개의 Source로 기록한다.

[반영·제외 기록](dprk-transcription-66.json), [현재 HTML 해시와 인용 대조](modern-excerpt-check-52.json).
`scripts/import_modern_excerpts.py --group dprk`로 재현한다. 전문과 별도 번역문은 이번 발췌 범위에 포함되지 않는다.
