# 본영의 선박 작업 장면

한산도 본영 설치 자료에 있던 전함 제작·수리 근거를 3D 구성에 연결했다. 본영 건물에 작업대·손수레·목재·작업 인물을 두고, 같은 섬의 가까운 해안에서 선착장과 물 위의 배를 배치한다. 이순신은 해당 활동의 근거가 있는 한산도에 놓인다. 작업 인원과 모형 간격은 설명용이며 실제 작업장 배치를 복원했다는 뜻은 아니다.

원래 카탈로그의 조형과 재질을 사용한다. 지원되지 않는 `repairing` 동작을 지정해 처음 화면 초기화가 실패한 문제를 고쳤고, 선박은 정박한 상태로 둔다. 시장·강학·건설·조정 활동도 해당 내용에 따라 다른 구성을 사용한다. 본영 제작 장면은 선박 활동이 확인된 건설 장면에 적용하며, 선박이 등장하는 공성전을 본영으로 바꾸지 않는다. 상대 함대는 침입 측 근거가 있는 경우에 구성한다.

로컬 실제 자료 검사에서 한산도 본영의 작업대·작업 인물·물 위 선박, 인물의 활동·장소·근거, 기존 해전과 인쇄 장면을 확인했다. #106의 작은 섬 지표 검사까지 포함해 29개 PASS, 브라우저 오류 0이다. 추가 시대 자료와 현대 장비 표현은 아직 통합 중이며 #101 전체 완료를 뜻하지 않는다.
