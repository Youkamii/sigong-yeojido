# 성곽·지역 전투·유적 조사 (#135)

실제 Claude Opus 5 / Max 두 작업에서 22개 출처, 65개 짧은 인용, 137개 Claim을 수집했다. 원문 해시·연도·장소·인물 관계를 확인해 장면 20개를 연결했다.
삼년산성·명활성·고창읍성, 대야성·공산·고창·담양·관음포·경원·청주·평양·황룡촌·홍주 기록과 송국리·검단리·암사동 조사가 포함된다.

유적 조사 3개는 현대의 발굴 장면이다. 선사시대 거주 연도를 새로 확정하지 않았다.
성곽 축조에는 성벽·작업 도구를, 점거에는 성곽을, 대야성에는 근거가 있는 창고 화재만 그린다. 담양에 나주 공격을 옮기지 않았다.
같은 이름인 고창읍성(전북)과 고창전투(안동)는 별도 장소다. 팔공산은 기존 산 좌표를 쓰며 정확한 전장이 아님을 표시한다.

관음포 해전·제너럴셔먼호 사건의 물 위 기준점 2개는 미확정이므로 연표와 관계에서 탐색한다. 육지 중심점에 배를 놓지 않는다.
지도 참조점 18개와 건물 배치·수량은 설명용이다. 성의 실제 윤곽이나 정확한 진형의 복원이 아니다.

수집 원본과 통합 검토를 구분한다. `scripts/review_local_scenes.py`는 원본을 보존하고 검토본을 만든다.
검토본·실제 실행 모델·출처 해시는 `data/research/scenes-135`에, 가져오기 검사 결과는 이 폴더의 `forts-import-135.json`, `conflicts-import-135.json`에 있다.

삼년산성은 연결된 470~660년 기록 사이, 명활산성은 431~647년 기록 사이에 성곽 배경을 이어서 보여준다.
이는 연속 점유가 확인된 기간이 아니라 표시상의 추정이다. `Place`를 선택하면 추정 설명과 실제 날짜가 있는 사건 3개씩으로 이동한다.
실제 사건이 표시되는 해에는 중복 배경을 만들지 않으며 사료 선택과 ‘성곽·마을·밭·동물’ 표시를 따른다.
성의 실제 존속 기간·폐성 연도를 새 Claim으로 만들거나 연표의 사건 수를 늘리지 않았다.
