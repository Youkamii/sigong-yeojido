# 시간 화면의 자료 공백 (#96)

2026-09-07 사용자가 "역사적 사실 이것밖에 안돼? claude로 조사한거 없어?"라고 지적했다.
기존 수집 기록과 현재 c2 `/api/chronicle` 응답을 실제 화면의 `contextAt` 함수로 대조했다.
이 문서는 Codex의 구현·데이터 연결 점검이다. 새 역사 조사나 Claude 수집을 했다는 보고가 아니다.

## 확인한 수집 기록

[기존 Opus 수집](periods-92.md)은 Opus 5 / Max 네 호출, 항목 42개, 발췌 153개, 날짜·관계 기록 210개다.
`data/research/periods-92/*/run.json` 네 파일에 요청 모델과 관찰된 모델 `claude-opus-5`, effort `max`, 종료 코드 0이 남아 있다.
한국사 전체에 필요한 인물과 사건을 채운 규모가 아니다.

## 남은 일

1. 기존 원문의 날짜·사건 참여 기록 중 화면으로 연결되지 않은 부분을 대조한다.
2. 빈 시대의 핵심 인물 생몰·재위·활동, 사건 날짜·참여자·장소를 실제 Claude Opus 5 / Max 수집으로 보강한다.
3. 같은 이름의 항목을 자동 합치거나 미상 날짜를 추정하지 않고, 통합 후 시대별 실제 노출량을 다시 확인한다.
