# 연도에 맞는 장소 #112

좌표 등록부 436개는 위치를 찾는 참고 자료다. 이 목록을 모든 연도의 지명으로
그리던 동작을 제거했다. 지도 라벨·이동 목록·장소 카드는 현재 선택한 사료와
연도의 사건·지속 활동에 연결된 장소를 함께 사용한다. 연도·사료 변경으로
장소가 사라지면 열려 있던 카드도 닫힌다. 자연 지형인 섬·산맥·봉우리는 유지한다.

1500년 한성부 표시, 현대 행정명 제거, 1700년 열린 카드 갱신, 1911년 수도 활동 종료,
1952년 부산 임시수도, 사료 전체 해제, 자연 지형 이동과 브라우저 오류를
실제 c2 API를 사용한 로컬 화면에서 검사했다. [8개 검사 통과](period-geography-112.json).
JS 조형·좌표 검사도 통과했다. 좌표가 있다는 이유만으로 새 존속 기간을 만들지 않았다.
이 변경으로 한국사의 모든 지역·모든 연도를 수록한 것은 아니다.
