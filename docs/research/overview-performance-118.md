# 넓은 화면의 접촉 음영 비용 — #118

`58870097` 공개판에서 배경까지 생성한 뒤 전체 보기의 장면 호출이 2,076회·삼각형 약 445만 개였다.
SSAO가 전체 장면의 법선·깊이를 다시 그리기 때문이다. 가까운 물체 밑에 붙는 미세 음영은 먼 화면에서
구분하기 어려워도 장면 전체를 처리하는 비용은 그대로 남았다.

이 역사 지도는 카메라 거리가 400을 넘으면 SSAO만 생략하고, 다시 확대하면 선택한 품질에 맞게 복구한다.
태양 그림자·지형·나무·건물·인물·필드는 유지한다. 저화질과 물질화 중의 기존 설정도 따른다.

같은 로컬 실행 경로·RTX 3060·1920×1080·medium에서 배경 생성 후 전체 보기의 실제 프레임 간격을 쟀다.
장면 호출 2,076→1,045회, 삼각형 4,455,798→2,227,906개, 실제 평균 82.0→136.3fps였다.
전후 네트워크가 같은 로컬 측정이다. 지역 이동은 159.2fps였다.
