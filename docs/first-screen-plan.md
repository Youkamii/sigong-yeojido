# 시공여지도 첫 화면 걷어내기 — 최종 안 v1

작성: Claude(디자이너), 2026-09-09. v0 초안 → 적대적 리뷰(강지우: 중2 + UX 리서처) + 조언적 리뷰(윤서현: 교육앱 디자이너) → 종합.
전제: 타겟 중고등학생, 패드 터치 우선, 남은 시간 1주, 판톨로지 코어 불변, 근거 없으면 답하지 않음·판정하지 않음.

## 1. 두 리뷰가 같이 말한 것 (그대로 채택)
- **지우지 말고 숨긴다.** index.html 인라인 스크립트 1,044줄이 69개 조작과 얽혀 있어 지우면 참조가 깨진다. `body.simple` 클래스 하나로 기존 패널을 전부 숨기고, 메뉴(≡) 서랍으로 옮긴다. 첫날 저녁에 "지도 하나" 화면이 나온다.
- **게이트는 삭제가 아니라 로딩 화면으로 강등.** 초기 준비 13~15초(데스크톱 실측, 패드 미측정). 대동여지도 위에 진행 막대 + "1593년으로 가는 중" 한 줄. 끝나면 1.2초 녹아 사라진다. 클릭은 없앤다.
- **챗은 검색 대체가 아니다.** 서버 Claude 구독 로그인 하나에 묶여 있고, 근거 없으면 "답할 근거가 부족하다"가 뜬다. 중고생은 타이핑보다 탭한다. → 챗은 "막힐 때 여는 문". 서랍을 열면 입력칸보다 **추천 질문 칩 6개**가 먼저. 칩은 현재 연도 ±50년 장면 패킷 제목에서 자동 생성(근거 있는 것만 칩이 된다).
- **"다른 눈으로 보기"는 지금 데이터로는 죽은 버튼.** 렌즈 15개는 전부 국내 사료·현대 연구다. 일본·미국 화자 사료가 없다. → 이번 주는 "조선 기록 / 현대 연구" 두 눈만. 카드 제목 옆에 눈 아이콘+숫자(👁 2)로 항상 노출하되 1이면 회색. 해외 화자 데이터 확보는 다음 주 이후.
- **온보딩은 팝업 금지.** 화면 안 손짓(SVG 손 아이콘 애니메이션) + 하단 한 줄 문구. 사용자가 그 동작을 실제로 하면 즉시 사라진다.
- **확대는 연속 핀치가 아니라 단계 스냅.** 더블탭 = 한 단계 확대, 두 손가락 탭 = 한 단계 축소, 휠도 한 칸 = 한 단계. 기존 `sceneZoomIn/Out`(0.7배/1.4배)이 이미 계단식이라 제스처만 물린다.

## 3. 적대적 리뷰만 짚은 것 (구현 조건으로 편입)
- **손가락 충돌.** 3D는 OrbitControls(한 손가락 회전, 두 손가락 확대·이동). 하단 바를 캔버스 밖 별도 HTML 영역(높이 120px)에 두고 `touch-action: pan-x`, 캔버스 `#three`에는 `touch-action: none`. 손잡이를 끌다 위로 새도 지도가 돌지 않는다.
- **탭했는데 안 열림.** 3D 픽 대상은 기둥 머리와 지도 피처뿐이라 인물·건물 모형을 탭하면 아무 일도 없다. → 탭 대상은 3D 픽이 아니라 **화면 위 HTML 표식(44px 원)** 으로 통일한다. 3D 좌표를 화면에 투영해 표식을 얹는다. 엔진을 안 건드리고 탭 영역도 보장된다.
- **점 281개 뭉침.** 폭 1,000px에 4,500년이면 1px = 4.5년. → 점은 개별 사건이 아니라 **10년 단위 밀도 점**(굵기 3단계). 손잡이가 지나갈 때 그 10년의 제목 하나가 0.3초 스친다. 기존 `/api/density`를 쓴다.
- **거리별 표시 전환이 엔진 카메라에 붙어야 하는가.** 카메라 거리를 매 프레임 재지 않는다. 단계 스냅이 있으니 **단계 전환 시점에만** 표식 예산을 바꾼다. 엔진 이벤트에 손댈 일이 없다.

## 5. 확대 3단계
| 단계 | 보이는 것 | 규칙 |
|---|---|---|
| 멀리 | 나라 영역·이름·도읍 점 + 표식 ≤3 | 현재 연도 ±25년 장면 패킷 중 점수 상위 3. 점수 = Claim 수×2 + 참여 인물 수 + 효과 있으면 +1. 같은 장소 하나만. |
| 중간 | 표식 ≤8 + 지명 | 같은 점수, 카메라 틀 안만. 지명은 기존 `_labelBudget()` 그대로. |
| 가까이 | 지금 장면 뷰 전부 | 인물 라벨은 이름만. 설명 줄은 카드로. |
(조언적 안의 "battle·siege면 +3" 가중치는 뺐다. 전투를 우대하는 것도 판정이다.)

## 8. 일주일 일정
**반드시 (D1~D4)**
- D1: `body.simple` 로 패널·탭·게이트 숨김. 하단 바+손잡이+연도(기존 timeline.js 슬라이더 재사용). 우상단 아이콘 2개 + 메뉴 서랍. `touch-action` 설정. → 이날 저녁 캡처로 "지도 하나" 확인.
- D2: 게이트 → 로딩 화면 + 녹아 사라짐. 시대 이름 줄 + "기록 적어요". 10년 밀도 점.
- D3: 확대 3단계 스냅(더블탭·두손가락탭·휠) + 단계별 HTML 표식 예산·점수.
- D4: 표식 → 하단 카드. [더 보기] = 기존 근거 패널을 서랍에 그대로. [👁 n] 렌즈 칩.
**되면 (D5~D6)**
- D5: 온보딩 손짓 3단계. 챗 서랍 추천 칩 6개.
- D6: **패드 실기기** 캡처 확인(1194×834 터치) + 폰 세로 한 번. 로딩 시간 실측.
**다음 주로**
- 근거 패널 상태 분리(evi·chronicle·tl 리팩토링), "내 나이로 가기", 진동 피드백, 라벨 겹침, 해외 화자 사료, 2D 정리.

## 9. 가장 먼저 터질 곳과 대비
D4의 카드 이식이다(적대적 리뷰 지적). 대비는 위의 "리팩토링 안 함, 기존 패널을 서랍에 그대로". 그래도 D4가 이틀을 넘기면 D5 온보딩을 버리고 D6 패드 확인은 지킨다. 패드 확인이 없으면 "패드 우선"은 말뿐이다.

## 10. 미확인
- 패드 실기기 로딩 시간과 프레임. 데스크톱 15초가 패드에서 몇 초인지 모른다.
- `touch-action: none` 을 캔버스에 넣었을 때 OrbitControls 제스처가 그대로 동작하는지. D1에 바로 확인.
- 장면 패킷 점수 상위 3개가 실제로 학생이 아는 사건과 겹치는지. 1592·1950·1919 세 연도로 D3에 눈으로 본다.
