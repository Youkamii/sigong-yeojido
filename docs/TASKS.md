## 8. 증거와 재현

기존 실행: Python 65개·JS 9개·운영 뷰어 12/12, 원문·그룹·응답 순서·3D 검사.
[운영 수용 기록](research/later-corpus-acceptance.json)의 범위에서 통과한 것이다.
이 테스트가 그래프·챗봇·역사 규칙·좁은 화면까지 검증한 것은 아니다.

이번 감사는 c2에 있는 실제 API·Fuseki를 읽고, 역사 규칙·시간 빌더에는 분리된 메모리 입력을 넣었다.
실제 주장·원문·digest를 변조하거나 서버를 재시작하지 않았다.
계보 순환은 기존 `descendantOf` 술어를 사용했다. 생몰·등장·순서 사례는 감사용 표현이며,
정식 술어·규칙 계약을 만드는 작업도 #54에 포함한다.

```bash
cd ~/sigong-yeojido
python3 scripts/audit_task_coverage.py --out /tmp/task-coverage.json
.venv-build/bin/python scripts/audit_viewer_coverage.py --out /tmp/viewer-coverage
```

HTTP 정적 제공은 HEAD로 확인했다. 형제 경로 접근·느린 연결 부하·서버 재부팅·외부 웹/법률 확인은 실행하지 않았다.
480px에서 근거 패널이 보이지 않는 [실제 PNG](research/viewer-coverage-480.png)를 직접 확인했다.
c2 원본은 `/tmp/sigong-viewer-coverage/480-evidence-hidden.png`다.
이번 감사에서는 기능 코드를 고치지 않았고, 누락 18개를 #46~#63으로 등록했다. 완료 후에도 이 이슈들은 열린 상태다.
