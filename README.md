# 시공여지도

**연도를 움직이면 그 해의 한국사가 지도 위에 나타난다. 지도의 모든 이름표는 원 사료로 이어진다.**

대동여지도는 1861년 조선의 지도다. 한 시점의 공간만 담는다. 시공여지도는 여기에 시간축을 붙였다. 고조선부터 현대까지 연도를 옮기면 나라의 경계, 도시, 사람, 사건이 그 해의 것으로 바뀐다. 그리고 화면에 뜨는 이름표 하나하나가 삼국사기, 조선왕조실록 같은 기록의 어느 대목에서 왔는지 보여준다.

## 화면

<p align="center">
<a href="https://sigong.rabbion.info/"><img src="docs/assets/readme/peninsula.jpg" width="95%" alt="1593년 한반도 전체 화면. 조선의 영역 위에 권율, 곽재우, 김천일, 유정 같은 인물 이름표와 평양성 탈환, 임진왜란 같은 사건 이름표가 놓여 있고, 아래에 연도 슬라이더가 있다."></a>
</p>

1593년, 임진왜란 한복판이다. 조선의 영역과 수도 한성부, 이 해에 살아 있던 권율과 곽재우, 이 해에 벌어진 평양성 탈환이 실제 자리에 놓여 있다. 아래 막대를 밀면 전부 다른 해로 바뀐다.

<p align="center">
<img src="docs/assets/readme/scene.jpg" width="49%" alt="1593년 진주성 장면을 가까이 본 화면. 성문과 성벽, 병사들, 기와집과 초가집, 시장 좌판이 3D로 세워져 있고 김천일과 최경회 이름표가 붙어 있다.">
<img src="docs/assets/readme/story-panel.jpg" width="49%" alt="김천일 이야기 패널. 제2차 진주성 전투 설명, 출생과 사망, 함께 참여한 인물 관계, 겪은 사건 연표, 이 이야기 더 물어보기 버튼이 보인다.">
</p>

확대하면 그 시대의 성곽과 집, 길, 사람이 보인다. 왼쪽은 진주성이다. 기록에 있는 것은 진하게, 기록이 없어 채워 넣은 배경은 흐리게 그린다.

이름표를 누르면 오른쪽처럼 패널이 열린다. 설명, 생몰년, 함께 있던 사람, 겪은 사건이 나오고 문장마다 출처가 달려 있다. 출처를 누르면 인용된 원문이 뜬다.

<p align="center">
<img src="docs/assets/readme/search.jpg" width="49%" alt="검색 결과 화면. 세종을 검색하면 인물 세종, 사건 경연, 관련 기록 월인천강지곡이 나오고 아래에 세종 설명과 한국민족문화대백과사전 출처 링크가 있다.">
<img src="docs/assets/readme/chat.jpg" width="49%" alt="AI와 역사 이야기 패널. 선택한 이야기 김천일 1593년이 표시되고, 추천 질문 두 개와 질문 입력창이 있다.">
</p>

검색창에 이름을 넣으면 인물, 사건, 관련 기록이 나뉘어 나온다. 하나를 고르면 그 연도, 그 자리로 지도가 옮겨 간다.

"AI와 역사 이야기"는 지금 보고 있는 이야기에 연결된 기록 안에서만 답한다. 답변 문장을 누르면 원문이 열린다. 기록에 없으면 없다고 한다.

설화와 전승은 역사 사건과 섞지 않는다. 처용, 서동, 아랑 전설 같은 이야기는 따로 목록이 있고 한 편씩 무대와 같이 본다.

## 사용법

1. [sigong.rabbion.info](https://sigong.rabbion.info/)를 연다. 화질을 고르고 들어간다. 패드나 오래된 기기는 "낮음"이 빠르다.
2. 아래 막대를 좌우로 끌거나 연도를 직접 친다. 시대 메뉴에서 고려, 조선을 바로 고를 수도 있다. 재생을 누르면 시간이 흐르고, 양옆 화살표는 사건이 있는 해로 건너뛴다. 기원전은 −500처럼 쓴다.
3. 지도는 끌어서 옮기고 휠로 확대한다. 오른쪽 버튼을 누른 채 끌면 돈다. "지도 설정"에서 시야를 이 시대 가까이, 한반도 전체, 주변국까지 중 하나로 바꾼다.
4. 이름표나 "사건 목록"에서 하나를 누르면 이야기 패널이 열린다.
5. 더 알고 싶으면 검색하거나 패널 아래 "이 이야기 더 물어보기"로 AI에게 묻는다.

지도 설정에서는 수도, 산과 섬, 인물과 사건 이름표, 국가 영역, 마을 같은 배경을 따로따로 끄고 켠다. 38도선 표시, AI 기능 끄기, 시간 막대 범위, 화질도 여기 있다.

## 원칙과 한계

- 근거 없는 말은 하지 않는다. 화면의 설명도 AI의 답도 수록된 기록의 인용을 달고 나온다. 근거가 없으면 "기록이 없다"고 답한다.
- 기록끼리 어긋나면 어느 쪽이 맞는지 정하지 않고 둘 다 보여준다.
- 추정은 추정이라고 적는다. 기록이 없는 마을, 밭, 동물은 "추정 배경 · 사료 없음"으로 표시하고 흐리게 그린다. AI가 그린 그림에는 "AI 생성 상상도"라고 붙인다.
- 국경선은 연구자들이 재구성한 자료(HGIS, Cliopatria)를 옮긴 것이다. 당시의 확정된 국경이 아니다.
- 기록에서 뽑은 설명은 AI가 초안을 쓰고 기계 검사를 거쳤다. 사람이 전부 검토했다는 기록은 아직 없다. 논문이나 수업에 쓰기 전에 출처를 눌러 원문과 맞춰 보길 권한다.

## 사료

원문은 국사편찬위원회가 공공데이터포털에 공개한 자료를 그대로 넣었다.

- 삼국사기, 삼국유사, 고려사, 고려사절요
- 조선왕조실록 전체, 승정원일기, 비변사등록, 고종·순종실록
- 광개토왕릉비, 한국고대금석문, 한국고대사료집성, 한국독립운동사자료
- 인물·사건 설명의 짧은 인용은 한국민족문화대백과사전에서 가져왔고 원 페이지 링크를 달았다
- 경계와 옛 행정구역은 HGIS와 Cliopatria, 해안선과 지형은 Natural Earth와 ETOPO 2022
- 시작 화면의 지도는 규장각 소장 대동여지도(퍼블릭 도메인)

자료별 입수처, 이용 조건, 확인 날짜는 [사료 목록](docs/01-sources.md)에 있다.

## 직접 실행

Python 3.11 이상. 다른 설치는 없다.

```bash
git clone https://github.com/Youkamii/sigong-yeojido.git
cd sigong-yeojido
python3 services/host/server.py --port 8870
```

`http://127.0.0.1:8870` 을 연다. 시작할 때 색인을 만들기 때문에 조금 기다린다.
저장소에는 사료 카드와 인용된 원문이 들어 있다. 실록, 승정원일기 전체 원문 같은 큰 파일은 따로 만들어야 한다. 전체 자료 준비, 그래프 검색(Fuseki), AI 대화 설정, 사료 추가 방법은 [개발·운영 안내](docs/DEVELOPMENT.md)를 본다.
