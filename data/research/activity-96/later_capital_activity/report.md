## 3. 수집한 원본

로봇 규칙 확인: `https://encykorea.aks.ac.kr/robots.txt` 를 다시 받아 `raw/encykorea-robots.txt` 로 남겼다. 금지 경로는 `/Article/Search`, `/Media/Search`, `/Article/WriterArticles`, `/Article/Hashtag` 이며 이 작업은 `/Article/{id}` 만 받았다(검색 경로 미사용). 타임아웃 15초·재시도 1회.

- **강화천도 항목은 새로 받지 않았다.** 형제 작업 `goryeo_scenes` 가 이미 받아 둔 바이트를 복사해 쓰고, 원 수집 기록(`fetchedUtc 2026-09-08T00:45:30Z`, httpStatus 200, byteLength 110142, sha256 d8e35f…)을 manifest 에 그대로 남겼다. 복사 후 sha256·바이트 길이를 다시 계산해 일치를 확인했다(`copy_reused()`).
- 항목 id 는 검색 경로 대신, 이미 받아 둔 형제 작업 raw HTML 안의 `/Article/E…` 링크를 훑어 찾았다(개경 E0079670, 한성부 E0061730, 부산 E0024209).

## 4. 검증 (build_result.py, 현재 `problems: []`)

1. 모든 발췌가 해당 raw 파일 본문(HTML 제거·공백 정규화)에 **그대로** 존재한다.
2. 소스 URL 1건당 발췌 총 어절 ≤ 25 (실측 23/22/20/16).
3. 연도 클레임의 숫자가 인용 발췌 문자열에 반드시 등장한다(919·1232·1270·1394·1910·1950·1953 모두 확인).
4. 장면이 참조하는 모든 claimId 가 출력 클레임에 있고, 클레임의 주어·대상 엔티티가 출력 엔티티에 있다.
5. 장면 `startYear`/`endYear` 가 각각 `dateClaimIds` 의 연도 클레임으로 뒷받침된다.
6. `effects.fire/ships/attack` 은 전부 `false` 이며, 활성화되면 검증이 실패하도록 했다.

시작·종료 근거가 다른 출처인 경우 연도 클레임을 둘로 나누고 장면이 둘 다 인용한다(개경 919–1232: 개경 항목 + 강화천도 항목, 개경 1270–1394: 강화천도 항목 + 한성부 항목).

## 5. 지속성 판단 근거 (첫·마지막 언급을 잇지 않았다)

- 개경: "강화도 천도기를 제외하고는 436년 8개월 동안 고려왕조의 수도로서 기능했다" — 강화기를 뺀 나머지 기간의 수도 기능을 출처가 직접 밝힌다. 그래서 919–1232, 1270–1394 두 구간으로 나눴다.
- 강화: "1270년(원종 11) 개경으로 환도할 때까지 고려의 국도가 되었다" — 종료 시점이 명시된 계속 상태다.
- 한성부: "1910년 경성부로 이름이 바뀔 때까지 515년간 조선왕조의 수도로서" — 종료가 명시된 계속 상태다.
- 부산: "1950년 8월 18일부터 1953년 8월 15일까지 임시수도" — 출처가 하나의 기간으로 적는다.

## 7. 사람·참여자 처리

재위·생몰만 보고 특정 인물이 그 기간 내내 그 도시에 있었다고 적지 않았다. 참여자는 출처 문장이 직접 적은 단위만 넣고 모두 `presence='related'` 로 두었다.

- 고려(개경 2구간·강화) — "고려왕조의 수도", "고려의 국도가 되었다"
- 조선(한성부) — "조선왕조의 수도로서"
- 부산으로 몰려든 피난민(신규 익명 집단) — "피난민이 몰려들어 인구가 급증하였다"

대한민국 정부는 넣지 않았다. 부산 항목 발췌가 "임시수도"라고만 적고 국가·정부를 명시하지 않기 때문이다.

## 8. 남긴 불확실성·공백 (result.json `missing` 5건)

1. 개경 항목 본문(강도 37년 10개월)과 주석(39년)의 기간 표기가 서로 다르다 — 어느 쪽도 장면 연도로 쓰지 않았다.
2. 한성부는 1895년 한성군으로 격하되었다가 1896년 회복되었는데도 출처는 1394–1910을 515년 수도 기간으로 서술한다 — 출처 서술대로 한 구간으로 두고 중간 변동은 장면화하지 않았다.
3. 한성부용 표시 앵커가 등록부에 없다 — anchorPlaceId 를 비웠다.
4. 부산 임시수도 기간 안의 정부 소재지 이동·환도 여부를 다루는 출처는 받지 않았다.
5. 1392년 조선 건국~1394년 한양 천도 사이 개경의 지위는 받은 발췌로 확인되지 않는다 — 개경 구간의 끝을 1394년 수도 이전으로만 잡았다.
