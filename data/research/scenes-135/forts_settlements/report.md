## 5. 재현 방법

```
python fetch.py "<url>###<파일명>"   # timeout 20s, 재시도 1회, manifest.json 갱신
python strip.py <raw 파일명>          # txt/ 에 태그 제거본
python build.py                      # 1~3번 출처(삼년산성·명활산성·고창읍성)까지 result.json 저장
python build2.py                     # 전체 재빌드 + 송국리·검단리·암사동 + missing
python validate.py                   # 참조 무결성 검사 (현재 errors 0)
```

robots 확인: encykorea 는 `/Article/Search` 등만 차단이라 `/Article/E00…` 는 허용, 위키백과·위키데이터는 `/w/` 와 `/api/` 가 차단이라 `/wiki/` 문서 경로만 받았다. NIKH/KCI/KISS/ITKC 는 요청하지 않았다.
