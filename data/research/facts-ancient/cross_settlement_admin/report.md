## 4. 판단 기록

- **연도 없는 chunk 의 시간 주장.** 지리지·집성 chunk 는 `date` 가 없다. 지리지는 본문의 연호를 그대로 verbatim 으로 썼다(`法興王十一年, 梁普通六年` → 524, `智證王六年, 梁天監四年` → 505, `眞興王十六年` → 555). 집성 동이전은 연도가 아예 없어 시간 주장을 `{kind:'year', value:245}` 로 두고, 245 가 사료의 연도가 아니라 3세기 중엽을 뜻하는 배치 연도임을 모든 claim·fact 의 note 에 적었다. `confidence` 는 medium.
- **본문에 연월 표기가 없는 본기 chunk**(678 북원소경, 680 금관소경, 685 남원소경, 660 백제 호수)는 `time.verbatim` 을 만들어 낼 수 없어 `{kind:'year'}` 를 썼다. chunk 의 `date.raw` 서기연과 값이 같으므로 검증기의 연도 대조는 그대로 걸린다.
- **호수 literal 의 자료형.** 작업 지시에는 `value` 를 문자열로 적으라고 되어 있으나, `scripts/fact_predicates.json` 의 `syj:householdCount` 는 `"numeric": true` 이고 검증기(`check_fact_research.py` 의 `claim()`)는 `number(obj['value'])` 를 요구한다. 문자열을 넣으면 실패한다. 그래서 **숫자**로 적었다. 단위 없는 `syj:administeredAs` literal(예: `小京`, `州主·郡主`)만 문자열이다.
- **원문 단위가 家 인 경우.** `syj:householdCount` 는 단위를 `戶` 로 강제하므로, 원문이 `一萬餘家`·`一千餘家`·`八十餘家` 인 3건(47·217·293)은 호수 주장을 만들지 않고 행위 주장을 근거로 `density {households, unit:'家'}` 만 채웠다.
- **어림수 환산.** `十餘萬戶` → 100000(하한), `四五萬戶` → 45000(중간값), `一萬餘家` → 10000. 모두 note 에 근거를 적었다.
- **권역.** 지침의 위도 규칙(north ≥39, central 37~39, south <37)을 그대로 따랐다. 충주(36.99)는 경계 바로 아래라 규칙대로 `south` 로 넣고 note 에 적었다. 757 년 9주 개명은 전국 조치라 조치가 내려진 왕경 기준으로 `capital` 로 두었다.
- **좌표.** 만들지 않았다. ko/en 위키백과 문서 머리의 표시 좌표(`class="geo"` 의 십진 좌표)를 그대로 발췌해 출처 10개를 만들고, 좌표를 쓴 사실·장면에만 붙였다. 김해·남원·완도·창녕은 한국어 문서에 십진 좌표가 없어 영어 위키백과를 받았다. 좌표는 **현대 시·군 중심**이지 옛 치소 자리가 아니므로 `precision:'area'` 와 `coordinateNote` 로 밝혔다. 아시촌·사도성·책성은 비정이 갈려 좌표를 넣지 않고 note 에 적었다.
- **db.history.go.kr 은 열지 않았다.** 원문은 전부 로컬 chunk 인용이다(chunkClaims 56 / excerptClaims 0). 웹은 좌표 발췌 전용이다.

### [minor] 7건

1. **fact-cross-s15 의 sceneId** — 요구대로 `scene-anc-cheonghaejin-abolition-851` 을 넣어 보았으나 검증기가 `facts[fact-cross-s15].sceneId/참조 없음` 으로 **FAIL** 을 냈다. `check_fact_research.py` 의 `fact()` 는 `self.refs([fact['sceneId']], scenes, ...)` 로 **같은 result.json 안의 scenes** 만 참조로 인정한다. 2. **fact-cross-a12 의 region capital** — 검수원의 두 번째 제안대로 **권역이 특정되는 개별 사실로 쪼갰다**. `a12` = 사벌주→상주(`region:'south'`, 상주 좌표), 새 `fact-cross-a14` = 한산주→한주(`region:'central'`, 좌표 없음). cell.regions 는 지시받은 `["south","central","north"]` 그대로 두었고 capital 칸은 0이 되었다. 장면 `scene-cross-757-nineju` 는 전국 조치가 내려진 왕경 기준이라 `region:'capital'` 을 유지했다(검증기의 커버리지 표는 scenes 가 아니라 facts 를 세므로 표에는 영향이 없다). 두 사실 모두 이 장면을 가리킨다.

4. **fact-cross-s09 의 density 좌표** — 검수원의 두 번째 선택지대로 `lon`·`lat`·`coordinateBasis` 를 **뺐다**. 사도성 비정이 미확정이라는 점과, `density` 의 80家 가 "어느 지점의 정주 밀도"가 아니라 "옮겨진 집단의 규모"라는 점을 fact note 와 `density.note` 에 적었다. 좌표가 없으므로 `build_fact_layers` 의 밀도 계산에 아예 들어가지 않는다. 제목과 어긋나던 `scene-cross-293-sadoseong.place` 도 null 로 바꾸고 이유를 summary 에 적었다.
