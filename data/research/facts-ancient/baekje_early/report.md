# baekje_early 조사 보고 (백제 · -18~300 · central)

## 1. 검색 방법

```
python scripts/search_chunks.py --source src-samguksagi --locator 百濟本紀 --from -18 --to 300 --limit 2000 --format table
python scripts/search_chunks.py --id chunk_samguksagi_sg_023_0020_0230
grep -l "伯濟" data/sources/jipseong-*/chunks.jsonl
python scripts/search_chunks.py --id chunk_jipseong-ko_022_ko_022_0350_0010
```

- 삼국사기 백제본기(권23~24)의 해당 구간 조각은 모두 **222개**다. 연도 범위와 locator 로 한 번에 뽑아 제목·연도 목록을 만든 뒤,
  갈래(취락·행정·시설·경제·재해·문화·대외·인물) 키워드로 후보를 좁히고 `--id` 로 원문 전문을 열어 확인했다.
- 집성은 `grep -l 伯濟` 로 `jipseong-ko_021`(후한서 한), `ko_022`(삼국지 위서 동이전 한), `ko_047`(한원), `ko_051`·`ko_056`(승전류)를 찾았고,
  호구 수치가 있는 **삼국지 한전**(`chunk_jipseong-ko_022_ko_022_0350_0010`)을 썼다. 이 조각은 `date` 가 null 이라 연도 일치 검사가 생략된다.
- `services/host/app/history-scenes.json` 의 294개 장면 중 -100~400년 구간은 7개(금성·감문국·평양성·태학·경주 월성·벽골제·이서국)뿐이고
  백제 한성기 장면은 하나도 없어, 여기서 만든 15개 장면은 기존 장면과 겹치지 않는다.
- db.history.go.kr 은 열지 않았다. 원문 근거는 전부 로컬 chunk 인용이고, 웹은 좌표용 위키백과 3건뿐이다.

### 결정사항

1. **위례성 좌표는 풍납토성 표시 좌표를 썼다.** 하남위례성=풍납토성 비정은 통설이지만 확정이 아니어서 `precision: area`, `confidence: medium`,
   coordinateNote 에 몽촌토성설을 적었다. 한산(漢山)은 몽촌토성 좌표를 후보로 따로 썼다.
2. **자리가 안 적힌 왕도 사건**(243년 대단 제사, 248년 진휼, 260년 관제 정비, 116년 한강 범람)은 왕도 대표점으로 풍납토성 좌표를 `area` 로 붙이고
   coordinateNote 에 "원문에 지점 없음"을 밝혔다. 지점을 만들어낸 것이 아니라 대표점임을 표시한 것이다.
3. **대두산성·탕정성·남택·패하/웅천 강역**은 현대 비정이 갈려 좌표를 넣지 않고 note 에 적었다(형식 규칙: 좌표를 못 구하면 lon/lat 을 넣지 않는다).
4. **삼국지 한전 조각은 date 가 없다.** 서술 하한인 정시 연간 기리영 사건(`二郡遂滅韓`)을 기준으로 연도를 246으로 잡고 note 에 근거를 적었다.
   마한의 범위는 central·south 에 걸치지만 이 칸이 central 이므로 백제국이 있던 central 로 집계했다.
5. **호구 수 literal 은 숫자로 적었다.** 지시문은 문자열을 권했지만 `scripts/fact_predicates.json` 의 `syj:householdCount` 에 `"numeric": true` 가 있어
   `check_fact_research.py`(280행)가 문자열을 거부한다. 검증기를 따라 1000·100000 같은 수로 넣고 단위는 `戶` 로 맞췄다.
   단위가 `家` 인 25년 남옥저 기사는 householdCount 를 쓰지 않고 `facts[].density` 로만 20가를 기록했다.
6. **시간 주장은 원문에 재위년 표기가 있을 때만 `time`** 으로 썼다(`元年`·`十四年`·`三十一年` 등 14건). 월만 적힌 기사는 `year` object 를 써서
   chunk 의 `date.raw` 서기연과 맞췄다. 지어낸 verbatim 은 없다.
7. **초기 기사 신빙성 논쟁**은 사실을 버리는 이유로 쓰지 않고 `confidence: medium` 과 note 로 남겼다(브리프 규칙 3).
