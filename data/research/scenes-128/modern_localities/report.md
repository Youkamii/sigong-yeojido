## 인용 원칙 점검

- 웹페이지당 인용 낱말: 목포항 20 / 신축교안 24 / 소록도 24 / 암태도 24 / 강주룡 23 / 조선어학회 24 / 장생포 22 / 고리 24 / 위키백과 4 / 위키데이터 4. 모두 25낱말 이하이며, 각 인용문이 HTML 제거·공백 정규화 후 원문에 그대로 연속으로 존재하는지 스크립트(`build.py`)로 확인했다.
- 현장 참여자는 이 행동에 대한 근거가 있는 사람만 넣었다.
  - 이재수: "이재수 등의 지휘 아래 … 제주성을 포위하였다" → on-site.
  - 최현배: "등 11명이 서울에서 구속되어 다음날 함경남도 홍원으로 압송되었다" → 홍원 현장.
  - 강주룡: 파업 주도 → 공장에서 쫓겨남 → 을밀대 지붕 등반이 한 문장 → on-site.
  - 서태석·박복영: 암태도에서의 조직·주도 문장 → on-site.
  - 조선어학회(단체)는 검거 대상 표기만 있어 `related` 로 두었다.
- 효과: 불·배는 전부 끔. 공격은 신축교안 한 곳만 켰고 근거는 "수천 명의 도민들이 제주성을 포위하였다" 문장이다. 병력 수·대열·불탄 건물은 만들지 않았다.
- 장소 주장은 모두 출처가 쓴 역사적 지명(목포항·제주성·대정·소록도·암태도·을밀대·홍원·장생포동 납도·고리)을 인용한다. 현재 주소 표기가 섞인 경우(소록도·고리)는 note 에 "현재 표기"라고 적었다.

## 확인하지 못한 연결 (구체 목록)

1. **제주해녀항일운동(1932, 구좌면 세화리)** — 지역·사회 사건으로 가장 넣고 싶었으나 원문을 못 받았다.
   - `https://www.jeju.go.kr/hangil/contents/haenyeo.htm` : jeju.go.kr robots.txt 가 `Disallow: /` 이고 허용 목록에 `/hangil/` 이 없다 → 요청하지 않음.
   - `https://jeju.grandculture.net/jeju/toc/GC00702600` : robots.txt 가 ClaudeBot·anthropic-ai 등 AI 크롤러에 `Disallow: /` → 요청하지 않음.
   - 한국민족문화대백과사전에는 해당 표제 항목을 찾지 못했다(사전 내부 검색 `/Article/Search` 가 robots 로 막혀 검색엔진 경유로만 탐색 가능).
   - **필요한 것**: 1932년 1월 세화리 시위의 날짜·장소·주도자를 밝힌, robots 가 허용하는 공공기관 원문 1건.
2. **거문도사건(1885~1887)** — 항구·섬 사건으로 적합하지만 거문도 좌표가 기존 등록부·앵커에 없다. 여수/돌산 앵커는 약 50㎞ 떨어져 있어 섬 위치로 쓸 수 없다고 보고 장면을 만들지 않았다. **필요한 것**: 거문도의 공공 실측 좌표 1건(국가유산청 등록유산 기록 등).
3. **지점 좌표 부재** — 을밀대 누각, 홍원경찰서 건물, 장생포동 납도, 소록도 병원 본관, 고리 발전소 부지, 제주성 성벽. 모두 `precision='area'` 로 두고 대표점과 실제 지점이 다르다는 사실을 각 `coordinateNote` 에 적었다. 지점 좌표가 확보되면 그대로 교체 가능하도록 좌표 출처를 장소 주장과 분리해 두었다.
4. **암태도 쟁의의 목포 국면** — 1924년 6월·7월 목포경찰서·법원 앞 시위는 같은 사건의 다른 장소다. 페이지당 25낱말 상한을 이미 다 써서 별도 장면(목포)을 만들지 않았다. 인용 여유가 생기면 목포 장면을 추가할 수 있다(좌표는 rc-mokpo-city 재사용 가능).
5. **울산 기공식 날짜** — 인용한 「장생포」 항목에는 1962년까지만 있고 월·일이 없다. 날짜가 필요하면 국가기록원 등 다른 공공 기록이 필요하다.
6. **고리 1971년 행정구역명** — 인용 항목이 현재 주소(부산광역시 기장군 장안읍 고리)만 적는다. 착공 당시 표기는 확인하지 못했다.

## 파일

- `result.json` — {sources, entities, claims, scenes, missing}. 장면마다 저장하며 갱신했다.
- `manifest.json` — 내려받은 17건(robots 4건 포함)의 url/fetchedUtc/httpStatus/byteLength/sha256/rawFile.
- `progress.json` — 완료 장면 수와 id 목록.
- `raw/` — 원본 응답 바이트. `txt-*.txt` 는 인용 검증용으로 만든 태그 제거본이다.
- `fetch.py`(내려받기), `strip.py`(태그 제거), `build.py`(인용문 연속성·낱말 수 검증), `emit.py`(result.json 생성·검증).
