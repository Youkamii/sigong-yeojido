### R1 — CHGIS/TGAZ 부재가 API 실패가 아님을 통제 질의로 확인

`真番`, `真番郡`, `眞番`, `霅` 네 문자열 모두 `Results: 1-0 of 0 total hits`. 같은 세션의 통제 질의는 좌표를 정상 반환했습니다.

- 樂浪郡 hvd_112642 / 112643 / 112645 — 모두 `[125.75502, 39.03258]`
- 玄菟郡 hvd_112640 `[127.42076, 39.85064]` (−108/−83), hvd_112641 `[124.85729, 41.70123]` (−82/0)
- 臨屯郡 hvd_112638 `[128.87792, 37.73960]` (−108/−82)

즉 이미 적재하신 낙랑·현도·임둔 점들과 값이 일치하며, 부재는 진번에 한정됩니다. `带方`/`帶方`도 0건입니다.

**라이선스 증거 (기존 적재분에도 적용):** hvd_112645 레코드 JSON이 CHGIS 데이터 라이선스를 **CC BY-NC 4.0**으로, 출처를 CHGIS(Harvard·復旦)로 명시합니다.

**호스트 이동 주의:** `maps.cga.harvard.edu/tgaz`는 404이고 `chgis.hudci.org/tgaz`로 이전했습니다. 기존 적재 파이프라인이 옛 주소를 쓰고 있다면 갱신이 필요합니다.

### R3 — 미상 서술 (통합 가능, 단 텍스트 전용)

한국민족문화대백과사전 「진번군(眞番郡)」(이형구, 1995 작성 / 2024-10-23 수정):

> 진번군의 위치와 강역에 대해서는 학자들 간에 복잡한 논의가 이루어지고 있다.

북방설(요동·고구려 지역·숙신 지역)과 남방설(진국·맥국·재령평야·대방 지역·마한 지역)로 정리하며, 사군 전체를 요서로 보는 견해도 언급합니다. 단일 통설을 제시하지 않습니다. 페이지에 **공공누리(KOGL) 공공저작물** 고지가 있습니다.

지도에서 진번 미상 주석·툴팁으로 인용 가능하나 **점·중심점·폴리곤으로 렌더링하면 안 됩니다.**

### R5 — 원전 텍스트 (통합 가능, 단 좌표 아님)

『史記索隱』(四庫全書本) 卷25는 朝鮮列傳第五十五를 포함하며, 該 항목의 주에 應劭의 주석이 실려 있습니다:

> 嘗略屬真番朝鮮〈如淳云燕嘗略二國以屬己也應劭云𤣥莬本直番國〉

현도 지역을 옛 진번국으로 보는 가장 오래된 직접 텍스트 근거이며, 북방설의 원전 축입니다. 저작권: 저자 사후 100년 초과·1931년 이전 간행으로 전 세계 퍼블릭 도메인, 사이트 텍스트는 CC BY-SA 4.0.

**주의 두 가지.** 첫째, 수용된 판본 표기가 `直番`(真番의 이체)·`𤣥莬`(玄菟의 이체)이므로 판독 전제가 붙습니다. 둘째, 이 주석은 **영역의 동일시**일 뿐 군치 지정이 아닙니다. 이를 근거로 CHGIS 玄菟郡 좌표를 진번에 붙이면 서로 다른 두 명칭을 합치는 것이 되므로 하지 마십시오.

## 확인하지 못한 것 (허위 완료 방지)

- **『茂陵書』의 「真番郡治霅縣, 去長安七千六百四十里, 十五縣」 인용은 검증 실패입니다.** zh.wikisource 『史記』卷115, 『史記三家註』卷115, ctext 『史記』朝鮮列傳, 『史記索隱』(四庫全書本) 卷25·26·27·28·29를 모두 열어 `茂陵`·`霅`·`七千六百`·`十五縣`을 찾았으나 전부 부재했습니다. 2차 문헌에 널리 인용되지만 허용 원전에서 직접 확인되지 않았으므로 findings에 넣지 않았습니다.
- **저장소 브리핑 파일 3종을 읽지 못했습니다.** `--restricted`로 파일 도구가 작업 폴더에 갇혀 있어 `hansagun-sites-49.md`, `chgis-date-codes-49.md`, `core-questions-goal.json`에 접근할 수 없었습니다. 전부 과제 브리프만으로 진행했으므로 해당 파일과의 중복·상충 여부는 미확인입니다.
- **KCI 논문 2편**(「진번 위치에 대한 재검토」, 「고대 진번의 변천 연구」)은 robots 금지 도메인이라 열지 않았습니다. 검색 결과 목록에서 존재만 알 뿐이며 직접 확인으로 전환하지 않았습니다. DBpia도 승인 제공처가 아니라 열지 않았습니다.
- **황해도설의 고고학적 근거**(사리원 당토성 / 장무이묘)는 기관 자료 수준까지 파고들지 않았습니다. 다만 검색 단계에서 이 자료가 **대방·고구려계 유물**로 진번보다 수백 년 늦다는 점이 드러났으므로, 어떤 경우에도 진번 유적으로 처리하면 안 됩니다.

## 부수 소득 (chgis-date-codes-49 스레드로 이관)

TGAZ 레코드 JSON에 `begin_rule` / `end_rule` 필드가 연도 값과 함께 노출됩니다. hvd_112645(樂浪郡)는 `begin=24, begin_rule=3, end=0, end_rule=0`입니다. 시작 24 CE에 종료가 실제 연도 0이면 시간 순서가 성립하지 않으므로, `end=0` + `end_rule=0`은 연도가 아니라 **미상·미설정 표지**로 작동한다고 보입니다.

이는 레코드 1건에서 나온 **추론이며 문서화된 규격이 아닙니다.** `chgis.hudci.org/tgaz/about`이 빈 본문을 반환해 코드표를 얻지 못했습니다. 해당 스레드 담당이 확인해 주십시오.
