## 실패·수정 목록

- 도구 실패·거부·최종 누락: 없음. 총 39회 호출(36건 + 검수 후 재생성 3회).
- 공통: 입력 prompt 원문을 유지하고 요청 해상도·방향, 문자·숫자·현대 물건·폭력·알려진 얼굴을 방지하는 문구를 덧붙였다. 변경 내용은 metadata의 promptNote에 기록했다.
- 입력은 문단 구분 없는 한 문단이므로 stylePrefix는 각 입력 prompt 전체다.
- je-hopae: 현대식 뚜껑 용기처럼 보이는 소품 발견. 전통 문방구·나무 도구만 두도록 1회 재생성 후 통과.
